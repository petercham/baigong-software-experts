## 触发与不触发

**该触发（正路由样例，用户会这样说话）**

1. 「这份 PRD 里哪句话是客户真说过的，哪些是我们自己推的？」→ 触发。
2. 「这张工作票说要在真实环境验，能改成 Mock 吗？」→ 触发。
3. 「这封函发出去之前，谁审过、谁批过？」→ 触发。
4. 「交付汇总里哪些只是 Mock、哪些根本没验？」→ 触发。
5. 「这段是不是我们自己吹的、有没有注水？」→ 触发（判 `evidence_tag`）。
6. 「客户口头改了口径，我们照着改了，这算哪一层？」→ 触发（走来源层判定序；口头未成文的按第 6 步归 `internal_assumption` 并注明「未成文」）。
7. 「这份东西现在能不能发出去、谁批的？」→ 触发（外发门与 `authorization`）。

**不该触发（负路由样例）**

1. 「把这个函数改成异步」→ 不触发。
2. 「把这张表的行距调一下」→ 不触发。
3. 「现在几点」→ 不触发。
4. 「帮我把这份行业报告的证据链补齐」→ 不触发（调研本体不在本技能）。
5. 「这票现在该谁签字」→ 不触发（状态机流程不在本技能）。
6. 「把这段翻成英文」→ 不触发。

注：上组第 7 条「能不能发出去、谁批的」问的是**外发授权**，走本技能外发门；本组第 5 条问的是**票型与状态机节点**，不属本技能。二者不重叠。

## 契约总则

1. 一句一主张，一行一 `claim`。
2. 每行必须填满 17 项必填字段，并按条件填 3 项条件字段。
3. `linked_artifacts` 至少一条来源引用（`source:` 或 `cite:`）；`artifact:` 只能附加，不得单独充当来源。
4. 内部接受不等于外部确认。
5. 内部冻结只限内部、必须带时效与复核人，不得外溢为默认认可。
6. 替代实现、占位、降级必须写明要求环境与检查、实际环境与检查、豁免、回退判据与重开条件。
7. 外发件必须先过事实审查、承诺审查与人类授权；审查人不得为生成方，两名审查人不得为同一人。
8. 数量、时点、标识、完备性断言必须可跨件比对；同键不同值即判违例。
9. 机器只校验结构、闭集、可比对性与引用；不判业务真伪，不作法律或合同解释。
10. 状态只增不改，历史不回写。

## 4. 可比对断言（表 B）与受限抽取模式

**可比对断言登记表（表 B）列**：`cmp_id` / `cmp_key` / `cmp_kind` / `cmp_value` / `completeness_mode` / `enumeration_count` / `remaining_count` / `claim_id` / `source_artifact`。

- 表 B 是**可比对断言行**的唯一登记处。**「唯一」指表只有一处**，不是「每个键只有一行」：同一 `cmp_key` 可以有多行，各行的 `source_artifact` 指名该数值由哪份工件给出；同键多行即构成跨件比对点（见 `30-gates` `R11`）。
- `cmp_id` 格式 `CMP-[0-9]{3,}`；`cmp_kind` ∈ `quantity` / `datetime` / `identifier` / `completeness`，须与所引主张的 `assertion_form` 相同。
- `cmp_key` 是「同一可识别对象」的键；**触发比对以 `cmp_key` 相等为条件，不以任何可选字段是否填写为条件**。
- `cmp_value` 是该对象的取值：数量为数值；时点为 `YYYY-MM-DD` 或 `YYYY-MM-DDThh:mm`；标识为被引编号；完备性为 `resolved`。
- `identifier` 类断言的 `cmp_value` 必须在**标识与需求主表（表 C）**已登记，且其 `definition_ref` 非 `none`。
- `completeness` 类断言必须填 `completeness_mode` ∈ `cleared` / `partial`，且 `enumeration_count` ＞ 0；`cleared` 时 `remaining_count` 必须 ＝ 0，`partial` 时 `remaining_count` 必须 ＞ 0。其他 `cmp_kind` 三列均写 `none`。

**受限抽取模式（闭集，语境化：先有断言引导词，再有数值或时点）**

| 类 | 模式（正则片段） |
|---|---|
| 数量（阿拉伯） | `(剩余\|还剩\|还缺\|缺口\|共\|合计\|总计\|已\|待\|完成\|核销)\s*[0-9]+(\.[0-9]+)?\s*(人日\|人\|天\|小时\|分钟\|次\|个\|条\|项\|处\|万元\|元\|%)` |
| 数量（中文） | `(剩余\|还剩\|还缺\|缺口\|共\|合计\|总计\|已\|待\|完成\|核销)\s*[一二三四五六七八九十百千万两]+\s*(人日\|人\|天\|小时\|分钟\|次\|个\|条\|项\|处\|万元\|元\|成\|倍)` |
| 时点 | `(于\|截至\|截止\|止于\|完成于\|清零于\|定于\|在)\s*(20[0-9]{2}-[0-9]{2}-[0-9]{2}\|[0-9]{1,2}月[0-9]{1,2}日)` |
| 完备性 | `(清零\|一条不剩\|无遗漏\|核销完毕\|关闭完毕\|验收完毕)\s*(于\|之日\|为止\|完成)` |

**收窄依据（口径变更，取代上一版的裸量词触发）**：上一版把 `全部` / `所有` / `一律` / `均已` / `全覆盖` 作为完备性触发词，这些词在纪律性文本里高频出现（本文件自身就有三处），会把普通工作票系统性误判为完备性断言并逼出假计数。本版改为**引导词＋数值或时点**的语境化模式，裸量词不再触发；`c20` 用四例普通工作票正样本与四例真断言正样本双向实跑固定这一收窄。

**标识类不做抽取兜底**：标识形态（线号、表号、条目号）与治理语汇大量重名，正则抽取误报高于漏报代价；其覆盖改由「申报 `assertion_form=identifier` 即强制入表 ＋ 表 C 可解析」承担。

**标识与需求主表（表 C）列**：`id_key` / `id_value` / `definition_ref` / `status` / `req_required_environment` / `req_required_checks` / `req_enumeration_base`。

- 表 C 同时承担两件事：**标识定义**（`id_key`／`id_value`／`definition_ref`／`status`）与 **原始需求的要求面**（`req_*` 三列）。二者共用一张表是因为 REQ 条目本身就是一种标识；分两张表会产生两处 `REQ-` 编号真源。
- `id_value` 是编号本体，`REQ-` 起头的行即「原始需求条目」；`id_key` 是分类键，且**`id_value` 以 `REQ-` 起头的行其 `id_key` 必须为 `需求`，非 `REQ-` 起头的行其 `id_key` 不得为 `需求`**——需求条目只认这一种识别口径，不得另立第二口径。
- `status` ∈ `defined` / `draft` / `retired`；`status ≠ defined` 的 `id_value` 不得被任何主张引用。
- `req_required_environment` ∈ 环境轴四值或 `none`；`req_required_checks` ∈ 检查轴五值子集（以 `;` 分隔）或 `none`；`req_enumeration_base` 为非负整数或 `none`（该需求的原始枚举基数）。
- 非 `REQ-` 行的三列 `req_*` 一律写 `none`。

## 7. 状态语义硬规则

1. `accepted` 不等于 `external_confirmed`；内部接受不得写成外部确认。
2. `frozen_assumption` 只限内部：`expiry`、`review_owner`、`reopen_trigger` 三者均不得为 `none`，`expiry=none` 直接判违例；不得外溢为默认认可。
3. `external_pending` 超时只触发复核与升级，不自动变为 `external_confirmed`。
4. `external_effect=outbound_authorized` 只能由人类闸设置。
5. `superseded` 保留旧行，不删除、不改写；被 `superseded` 的主张不得再被任何工件引用。
6. QA 按 `actual_environment` / `actual_checks` 判定通过，不回写 `required_environment` / `required_checks`。
7. `evidence_tag` 为 `UNKNOWN` 或 `STALE` 时，`status` 不得为 `accepted`，`authority` 不得为 `binding`，`external_effect` 不得为 `outbound_authorized`。

## 8. 人工闸七类（唯一真源）

以下七类事项必须人类拍板，机器与席位均不得代判：

1. 外部权威来源的确认。
2. 外发授权。
3. 需求降级或豁免的批准。
4. 范围或验收口径的变更。
5. 法律、合同或责任解释。
6. 外发动作本身。
7. 是否将沉默视为认可；默认一律不算。

## 9. 禁止工具自决八条

1. 不得从文本自行推断权威性。
2. 不得把 `UNKNOWN` 或 `INFERENCE` 自动升格为 `FACT`。
3. 不得把内部冻结自动转为外部确认。
4. 不得自动降级要求环境或要求检查。
5. 不得自动发送任何外发件。
6. 不得自动生成对外承诺。

8. 不得自动改写历史主张状态。

## 2. 登记闭包

- **唯一主张登记表**：每个项目只有一处表 A（主张）、一处表 B（可比对断言行）、一处表 C（标识与需求）、一处表 D（主张级验证）；路径由项目绑定层注入，本技能包不写死路径。

## 3. 交付汇总聚合字段（七桶＋分母，互斥且完备）

七个桶**互斥**，且必须**完备**——即七桶之和恒等于 `total_claims`。分桶按下列判定序取首个命中，不得跳序、不得重复计入：

1. `qa_result ∈ {failed, blocked}` → 计入 `failed`。
2. `actual_environment = unverified` → 计入 `unverified`。
3. `qa_result = passed_with_exemption` → 计入 `excluded_by_approval`。
4. `required_environment = none` → 计入 `not_required`（**本步必须先于第 5／6 步**：未提出要求环境的主张不参与环境实况分桶，故即便 `actual_environment` 落了 `mock`／`test`／`integration` 也不得记入 `mock_only`）。
5. `actual_environment = production` 且 `qa_result = passed_at_actual` → 计入 `real_env_passed`。
6. `actual_environment ∈ {mock, test, integration}` → 计入 `mock_only`。
7. 其余（`required_environment ≠ none` 且 `actual_environment = production` 且 `qa_result = pending`）→ 计入 `pending`。

| 字段 | 语义 |
|---|---|
| `total_claims` | 本次交付涉及的、在表 D 已登记的主张总数（分母＝表 D 行数） |
| `real_env_passed` | 判定序第 5 步命中数 |
| `mock_only` | 判定序第 6 步命中数（含 `integration`，不把 `integration` 掉出等式） |
| `unverified` | 判定序第 2 步命中数 |
| `failed` | 判定序第 1 步命中数 |
| `excluded_by_approval` | 判定序第 3 步命中数 |
| `pending` | 判定序第 7 步命中数 |
| `not_required` | 判定序第 4 步命中数 |

**守恒式（闭合，无游离项）**：`real_env_passed + mock_only + unverified + failed + excluded_by_approval + pending + not_required = total_claims`，且 `total_claims` 必须等于表 D 行数。任一行无法落入任一桶即判违例（不得默认放行，不得计入「未绿项」冲抵）。

**口径说明**：上一版把 `real_env_passed + mock_only + unverified` 三项当成闭式，导致 `production + passed_with_exemption`、`production + pending` 两类正常态掉出等式并被错误列入未绿项。本版改为七桶互斥完备，分母锚定表 D 行数。

**第 4 步前移的理由（治 `not_required` 恒不可达）**：上一版把「其余（含 `required_environment = none`）」放在第 7 步，而 `actual_environment` 闭集内没有 `none`，故凡 `required_environment = none` 的主张都会先被第 5 步 `actual_environment ∈ {mock, test, integration}` 吞进 `mock_only`——语义相反（未提要求被记成只在 Mock 验过），且 25 种「要求环境 × 实际环境」组合穷举下第 7 步命中 0，`not_required` 恒不可达。本版把「未提出要求环境」前移到第 4 步，并保留第 7 步承接「有要求、实况在 production、QA 未结论」这一真实剩余类。

def norm(s):
    """规范化：逐行去首尾空白→丢空行→连续空白压单空格。与 check-provenance 的条款摘要算法同口径。"""

def sha(s):
    return hashlib.sha256(s.encode("utf-8")).hexdigest()


def read(pkg, rel):

def split_row(line):
    """按未转义的 | 切分表格行，反斜杠转义的竖线保留为字面竖线。"""
    body = line.strip()
    if body.startswith("|"):
        body = body[1:]
    if body.endswith("|"):
        body = body[:-1]
    cells = re.split(r"(?<!\\)\|", body)
    return [c.strip().replace("\\|", "|") for c in cells]


def parse_table(text, ncols, start=None):
    """解析首个 ncols 列表格；start 给定时只从该标题之后开始找。"""
    lines = text.replace("\r\n", "\n").split("\n")
    if start is not None:
        off = None
        for i, l in enumerate(lines):
            if l.strip() == start:
                off = i
                break
        if off is None:
            raise Red("找不到小节：" + start)
        lines = lines[off:]
    rows = []
    seen = False
    for l in lines:
        if not l.strip().startswith("|"):
            if seen:
                break
            continue
        cells = split_row(l)
        if len(cells) != ncols:
            continue
        if all(re.fullmatch(r"[:\- ]*", c) for c in cells):
            continue
        rows.append(cells)
        seen = True
    if not rows:
        raise Red("解析不到 %d 列表格" % ncols)
    return rows


def region(text, heading):
    lines = text.replace("\r\n", "\n").split("\n")
    st = None
    for i, l in enumerate(lines):
        if l.strip() == heading:
            st = i
            break
    if st is None:
        raise Red("找不到小节：" + heading)
    en = len(lines)
    for j in range(st + 1, len(lines)):
        if re.match(r"^##\s", lines[j]):
            en = j
            break
    return "\n".join(lines[st:en])


def resolve_section(text, label):
    """按 40-provenance-map 的小节标签取正文：`§N` 取 `## N.` 整节；`§表头` 取首部引用块；
    `§主类型段` 取 `**主类型**：` 行。三类均须**存在且唯一**——这就是裁定九要求的「验节存在」。"""
    lines = text.replace("\r\n", "\n").split("\n")
    if label == "表头":
        st = None
        for i, l in enumerate(lines):
            if l.startswith(">"):
                st = i
                break
        if st is None:
            raise Red("找不到表头引用块")
        en = st
        while en < len(lines) and lines[en].startswith(">"):
            en += 1
        return "\n".join(lines[st:en])
    if label == "主类型段":
        hits = [l for l in lines if l.startswith("**主类型**：")]
        if not hits:
            raise Red("找不到主类型段")
        if len(hits) > 1:
            raise Red("主类型段出现 %d 次（须唯一）" % len(hits))
        return hits[0]
    pat = (r"^##\s+%s\." % re.escape(label)) if label.isdigit() else (r"^##\s+%s\s*$" % re.escape(label))
    hits = [i for i, l in enumerate(lines) if re.match(pat, l)]
    if not hits:
        raise Red("所指节不存在：§%s" % label)
    if len(hits) > 1:
        raise Red("所指节标题重复 %d 次：§%s" % (len(hits), label))
    st = hits[0]
    en = len(lines)
    for j in range(st + 1, len(lines)):
        if re.match(r"^##\s", lines[j]):
            en = j
            break
    return "\n".join(lines[st:en])

def _loc_index(lines, kind, key):
    """定位并断言**锚唯一**（裁定七：锚命中数必须恰为 1）。"""
    if kind == "region":
        hits = [i for i, l in enumerate(lines) if l.strip() == key]
    elif kind == "line":
        hits = [i for i, l in enumerate(lines) if l.startswith(key)]
    elif kind == "row":
        hits = []
        for i, l in enumerate(lines):
            if not l.strip().startswith("|"):
                continue
            cells = split_row(l)
            if cells and cells[0].replace("`", "") == key:
                hits.append(i)
    else:
        raise MutateFailed("未知定位类型：" + str(kind))
    if not hits:
        raise NotHere(str(key))
    if len(hits) > 1:
        raise MutateFailed("锚命中 %d 次（须恰 1 次）：%s" % (len(hits), key))
    return hits[0]


def apply_loc(text, loc, new):
    kind, key = loc
    lines = text.replace("\r\n", "\n").split("\n")
    i = _loc_index(lines, kind, key)
    if kind == "region":
        en = len(lines)
        for j in range(i + 1, len(lines)):
            if re.match(r"^##\s", lines[j]):
                en = j
                break
        out = "\n".join(lines[:i] + new.split("\n") + lines[en:])
    elif kind == "line":
        lines[i] = new
        out = "\n".join(lines)
    else:
        lines[i] = new
        out = "\n".join(lines)
    if out == text:
        raise MutateFailed("变异前后文本全等（未生效）：%s" % (key,))
    return out


def extract_loc(text, loc):
    kind, key = loc
    lines = text.replace("\r\n", "\n").split("\n")
    if kind == "region":
        return region(text, key)
    if kind == "line":
        return find_line(text, key)
    if kind == "row":
        i = _loc_index(lines, kind, key)
        return lines[i]
    raise Red("未知定位类型：" + kind)

def pkg_read(pkg, rel):
    with open(os.path.join(pkg, rel), encoding="utf-8") as f:
        return f.read()


def pkg_write(pkg, rel, text):
    with open(os.path.join(pkg, rel), "w", encoding="utf-8", newline="\n") as f:
        f.write(text)


def pkg_swap_words(pkg, rel, a, b):
    """互换两处字面（裁定七：两锚命中数各须恰为 1）。"""
    t = pkg_read(pkg, rel)
    if t.count(a) != 1:
        raise MutateFailed("互换锚 %r 命中 %d 次（须恰 1 次）" % (a, t.count(a)))
    if t.count(b) != 1:
        raise MutateFailed("互换锚 %r 命中 %d 次（须恰 1 次）" % (b, t.count(b)))
    t = t.replace(a, "\x00").replace(b, a).replace("\x00", b)
    pkg_write(pkg, rel, t)


def pkg_replace(pkg, rel, old, new):
    """按字面替换单处（裁定七：命中数必须恰为 1）。"""
    t = pkg_read(pkg, rel)
    if t.count(old) != 1:
        raise MutateFailed("替换锚 %r 命中 %d 次（须恰 1 次）" % (old[:48], t.count(old)))
    out = t.replace(old, new, 1)
    if out == t:
        raise MutateFailed("变异前后文本全等（未生效）：%r" % (old[:48],))
    pkg_write(pkg, rel, out)


def pkg_swap_fm(pkg, rel):
    t = pkg_read(pkg, rel)
    n = re.search(r"^name:\s*(\S+)\s*$", t, re.M)
    v = re.search(r"^version:\s*(\S+)\s*$", t, re.M)
    if not n or not v:
        raise MutateFailed("frontmatter 锚不存在（name=%s version=%s）" % (bool(n), bool(v)))
    if t.count(n.group(0)) != 1 or t.count(v.group(0)) != 1:
        raise MutateFailed("frontmatter 锚不唯一")
    t = t.replace(n.group(0), "name: " + v.group(1)).replace(v.group(0), "version: " + n.group(1))
    pkg_write(pkg, rel, t)


def pkg_swap_header(pkg, rel, ncols, ca, cb):
    t = pkg_read(pkg, rel)
    lines = t.split("\n")
    hit = None
    for i, l in enumerate(lines):
        if not l.strip().startswith("|"):
            continue
        cells = [c.replace("`", "") for c in split_row(l)]
        if len(cells) == ncols and ca in cells and cb in cells:
            if hit is not None:
                raise MutateFailed("表头锚命中多于 1 行（%d 列）" % ncols)
            hit = i
    if hit is None:
        raise MutateFailed("表头锚不存在（%d 列 %s/%s）" % (ncols, ca, cb))
    cells = [c.replace("`", "") for c in split_row(lines[hit])]
    a, b = cells.index(ca), cells.index(cb)
    cells[a], cells[b] = cells[b], cells[a]
    lines[hit] = "| " + " | ".join(cells) + " |"
    pkg_write(pkg, rel, "\n".join(lines))


def pkg_mkdir(pkg, rel):
    os.makedirs(os.path.join(pkg, rel), exist_ok=True)


def pkg_rename(pkg, a, b):
    if not os.path.exists(os.path.join(pkg, a)):
        raise MutateFailed("改名锚不存在：" + a)
    os.rename(os.path.join(pkg, a), os.path.join(pkg, b))


def pkg_dropprefix(pkg, rel, prefix):
    lines = pkg_read(pkg, rel).split("\n")
    hits = [l for l in lines if l.startswith(prefix)]
    if len(hits) != 1:
        raise MutateFailed("删行锚 %r 命中 %d 次（须恰 1 次）" % (prefix, len(hits)))
    pkg_write(pkg, rel, "\n".join(l for l in lines if not l.startswith(prefix)))


def pkg_inject(pkg, rel, after_prefix, extra):
    """在指定行之后插入一行——用于「把别处正文复制过来」这类第二真源变异。"""
    lines = pkg_read(pkg, rel).split("\n")
    hits = [i for i, l in enumerate(lines) if l.startswith(after_prefix)]
    if len(hits) != 1:
        raise MutateFailed("插入锚 %r 命中 %d 次（须恰 1 次）" % (after_prefix, len(hits)))
    lines.insert(hits[0] + 1, extra)
    pkg_write(pkg, rel, "\n".join(lines))

# ---------------------------------------------------------------- 变异算子
def mut_del(text, loc):
    return apply_loc(text, loc, "")


def mut_rev(text, loc):
    return apply_loc(text, loc, reverse_text(extract_loc(text, loc)))


def mut_pad(text, loc):
    return apply_loc(text, loc, extract_loc(text, loc) + " 补充说明见附注。")


def mut_sub(text, old, new, key=None):
    """字面替换。裁定七：锚命中数必须恰为 1，否则记 MutateFailed 使整轮失败。"""
    n = text.count(old)
    if n == 0:
        raise NotHere(old[:40])
    if n > 1:
        raise MutateFailed("字面锚命中 %d 次（须恰 1 次）：%r" % (n, old[:40]))
    out = text.replace(old, new, 1)
    if out == text:
        raise MutateFailed("变异前后文本全等（未生效）：%r" % (old[:40],))
    return out


def mut_sub_all_rows(text, ncols, start, col, old, new):
    lines = text.replace("\r\n", "\n").split("\n")
    off = None
    for i, l in enumerate(lines):
        if l.strip() == start:
            off = i
            break
    if off is None:
        raise NotHere(start)
    hit = 0
    for i in range(off, len(lines)):
        if not lines[i].strip().startswith("|"):
            if hit:
                break
            continue
        cells = split_row(lines[i])
        if len(cells) != ncols or all(re.fullmatch(r"[:\- ]*", c) for c in cells):
            continue
        if col < len(cells) and cells[col] == old:
            cells[col] = new
            lines[i] = "| " + " | ".join(cells) + " |"
            hit += 1
    if not hit:
        raise NotHere(old)
    return "\n".join(lines)

def run_check(cid, pkg):
    for c, t, fn in CHECKS:
        if c == cid:
            return fn(pkg)
    raise Red("未知检查号 " + cid)


def _collect_muts():
    muts = []
    for item in build_mutations():
        cid, name, fn, key, group = item
        muts.append((cid, name, key, fn, group))
    for e in EXPECT_TARGETS:
        muts.append((e["check"], "OP-del %s 删值" % e["id"], e["key"], (lambda t, e=e: mut_del(t, e["loc"])), "OP"))
        muts.append((e["check"], "OP-rev %s 等长反义" % e["id"], e["key"], (lambda t, e=e: mut_rev(t, e["loc"])), "OP"))
        muts.append((e["check"], "OP-pad %s 加噪" % e["id"], e["key"], (lambda t, e=e: mut_pad(t, e["loc"])), "OP"))
    return muts


def run_mutations(pkg):
    base = os.path.abspath(pkg)
    bitten = []
    fake = []
    mfail = []
    per = {}

    def bump(cid, kind):
        per.setdefault(cid, {"bite": 0, "miss": 0, "fail": 0})[kind] += 1

    # 结构面（文件级）
    for cid, name, fn in PKG_MUT:
        tmp = tempfile.mkdtemp(prefix="semgov-x-")
        dst = os.path.join(tmp, os.path.basename(base))
        shutil.copytree(base, dst)
        try:
            try:
                fn(dst)
            except MutateFailed as exc:
                mfail.append((cid, name, "MUTATE_FAILED " + str(exc)))
                bump(cid, "fail")
                continue
            try:
                out = run_check(cid, dst)
                fake.append((cid, name, "假通过（变异已生效但仍报 %s）" % out))
                bump(cid, "miss")
            except Red as exc:
                print("BITE %-4s %-56s -> %s" % (cid, name, str(exc)[:80]))
                bitten.append((cid, name))
                bump(cid, "bite")
        finally:
            shutil.rmtree(tmp, ignore_errors=True)

    # 内容面
    muts = _collect_muts()
    for cid, name, key, fn, group in muts:
        done = False
        for rel in ([KEY_INV[key]] if key else FILES):
            src = os.path.join(base, rel)
            with open(src, encoding="utf-8") as f:
                orig = f.read()
            try:
                new = fn(orig)
            except NotHere:
                continue
            except MutateFailed as exc:
                mfail.append((cid, name, "MUTATE_FAILED " + str(exc)))
                bump(cid, "fail")
                done = True
                break
            except Red as exc:
                mfail.append((cid, name, "MUTATE_FAILED 变异器抛红：" + str(exc)))
                bump(cid, "fail")
                done = True
                break
            if new == orig:
                # 锚在本文件未命中（变异器对该文件不适用）——换下一个文件试
                continue
            tmp = tempfile.mkdtemp(prefix="semgov-m-")
            dst = os.path.join(tmp, os.path.basename(base))
            shutil.copytree(base, dst)
            with open(os.path.join(dst, rel), "w", encoding="utf-8", newline="\n") as f:
                f.write(new)
            try:
                try:
                    out = run_check(cid, dst)
                    fake.append((cid, name, "假通过（变异已生效但仍报 %s）" % out))
                    bump(cid, "miss")
                except Red as exc:
                    print("BITE %-4s %-56s -> %s" % (cid, name, str(exc)[:80]))
                    bitten.append((cid, name))
                    bump(cid, "bite")
            finally:
                shutil.rmtree(tmp, ignore_errors=True)
            done = True
            break
        if not done:
            mfail.append((cid, name, "MUTATE_FAILED 锚在本包任一文件均不存在"))
            bump(cid, "fail")

    print("")
    for cid, name, why in mfail:
        print("!! %-4s %-56s -> %s" % (cid, name, why))
    for cid, name, why in fake:
        print("?? %-4s %-56s -> %s" % (cid, name, why))
    total = len(PKG_MUT) + len(muts)
    print("变异体合计 %d 条（结构面 %d ＋ 内容面 %d）" % (total, len(PKG_MUT), len(muts)))
    print("  咬住 %d 条 / 假通过 %d 条 / MUTATE_FAILED %d 条" % (len(bitten), len(fake), len(mfail)))
    ids = sorted(per)
    print("逐判据覆盖：" + " ".join("%s=%d/%d" % (c, per[c]["bite"], per[c]["bite"] + per[c]["miss"] + per[c]["fail"]) for c in ids))
    covered = [c for c in ids if per[c]["bite"] > 0 and per[c]["miss"] == 0 and per[c]["fail"] == 0]
    miss = [c for c, _t, _f in CHECKS if c not in covered]
    if miss:
        print("未获有效覆盖的判据（须有咬住且零假通过零失败）：" + " ".join(miss))
    ok = (not mfail) and (not fake) and (not miss)
    print("判定：%s" % ("全绿（%d 条全咬、零假通过、零失败、覆盖 %d/%d）" % (len(bitten), len(covered), len(CHECKS)) if ok else "不通过"))
    return 0 if ok else 1


def selfcheck(pkg):
    """裁定七：夹具自证。锚唯一性 + 正则命中数 + 源码转义体检 + 形态自洽。"""
    bad = 0
    print("== 1) 变异锚唯一性（每个靶点的 loc 在其目标文件命中恰 1 次）==")
    n_anchor = 0
    for e in EXPECT_TARGETS:
        try:
            txt = read(pkg, e["file"])
            lines = txt.replace("\r\n", "\n").split("\n")
            i = _loc_index(lines, e["loc"][0], e["loc"][1])
            assert i >= 0
            n_anchor += 1
        except (NotHere, MutateFailed, Red) as exc:
            bad += 1
            print("!! 靶点 %s 锚不合格：%s" % (e["id"], exc))
    print("   靶点 %d 个，锚唯一命中 %d 个，不合格 %d 个" % (len(EXPECT_TARGETS), n_anchor, bad))

    print("== 2) 正则体检（编译通过 + 在声明探针上命中数符合声明 + 普通票零命中）==")
    regs = [re.compile(p) for _, p in PATTERNS_PAIRS]
    for idx, probe, want in PATTERN_PROBES:
        got = len(regs[idx].findall(probe))
        okk = got == want
        print("   %-12s 探针 %-22r 命中 %d（声明 %d）%s" % (PATTERNS_PAIRS[idx][0], probe, got, want, "OK" if okk else "FAIL"))
        if not okk:
            bad += 1
    plain_hits = 0
    for s in PLAIN_SAMPLES:
        for rgx in regs:
            plain_hits += len(rgx.findall(s))
    print("   普通工作票样句 %d 例 × %d 模式：命中 %d（声明 0）%s" % (len(PLAIN_SAMPLES), len(regs), plain_hits, "OK" if plain_hits == 0 else "FAIL"))
    if plain_hits:
        bad += 1

    print("== 3) 源码转义体检（本夹具源码内不得出现双斜杠转义）==")
    with open(os.path.abspath(__file__), encoding="utf-8") as f:
        own = f.read()
    body = re.sub(r'"""[\s\S]*?"""', "", own, count=1)
    found = []
    for tok in ("/" + "/s", "/" + "/S", "/" + "/d", "/" + "/w", "/" + "/b", "/" + "/D", "/" + "/W"):
        if tok in body:
            found.append(tok)
    print("   双斜杠转义命中 %d 处（声明 0）%s" % (len(found), "OK" if not found else "FAIL " + repr(found)))
    if found:
        bad += 1

    print("== 4) 形态自洽（25 条各恰 1 个形态标签；分布总数＝检查数）==")
    cids = [c for c, _t, _f in CHECKS]
    miss_form = [c for c in cids if c not in FORM_REASONS]
    extra_form = [c for c in FORM_REASONS if c not in cids]
    badtag = [c for c in cids if c in FORM_REASONS and FORM_REASONS[c][0] not in FORM_TAGS]
    print("   检查 %d 条；缺形态 %d 条；多余形态 %d 条；非法标签 %d 条" % (len(cids), len(miss_form), len(extra_form), len(badtag)))
    if miss_form or extra_form or badtag:
        bad += 1

    print("== 5) 变异生成器自洽（每条内容面变异在本包内至少一处可生效）==")
    inert = []
    base = os.path.abspath(pkg)
    for cid, name, key, fn, group in _collect_muts():
        hit = False
        for rel in ([KEY_INV[key]] if key else FILES):
            with open(os.path.join(base, rel), encoding="utf-8") as f:
                orig = f.read()
            try:
                new = fn(orig)
            except (NotHere, MutateFailed, Red):
                continue
            if new != orig:
                hit = True
                break
        if not hit:
            inert.append((cid, name))
    print("   内容面变异 %d 条，可生效 %d 条，失效 %d 条" % (len(_collect_muts()), len(_collect_muts()) - len(inert), len(inert)))
    for cid, name in inert:
        print("   !! 失效：%s %s" % (cid, name))
    if inert:
        bad += 1

    print("== 判定：%s ==" % ("自证全绿" if bad == 0 else "自证不通过（%d 项）" % bad))
    return 0 if bad == 0 else 1

def main(argv):
    if len(argv) < 2:
        print(__doc__)
        return 2
    if argv[1] == "--list":
        for c, t, _ in CHECKS:
            print("%-4s %s" % (c, t))
        return 0
    if argv[1] == "--all":
        pkg = argv[2]
        bad = 0
        for c, t, fn in CHECKS:
            try:
                msg = fn(pkg)
                print("OK   %-4s %s" % (c, msg))
            except Red as exc:
                bad += 1
                print("FAIL %-4s %s" % (c, exc))
            except (MutateFailed, NotHere) as exc:
                bad += 1
                print("FAIL %-4s 夹具异常：%s" % (c, exc))
        return 0 if bad == 0 else 1
    if argv[1] == "--mutate":
        return run_mutations(argv[2])
    if argv[1] == "--stats":
        return stats(argv[2])
    if argv[1] == "--selfcheck":
        return selfcheck(argv[2])
    if len(argv) < 3:
        print("用法：verify.py <check-id> <pkg-dir>")
        return 2
    try:
        msg = run_check(argv[1], argv[2])
        print("OK   %-4s %s" % (argv[1], msg))
        return 0
    except Red as exc:
        print("FAIL %-4s %s" % (argv[1], exc))
        return 1


if __name__ == "__main__":

## 3.13 SHA 对账（真实仓可跑版，治修3-05／裁定八）

```bash
set -o pipefail
W="$(mktemp -d)"
RCP=".scratch/tickets/2026-11-07-SEMGOV-T1-v4-receipt.md"
test -f "$RCP" || { echo RECEIPT_ABSENT; exit 1; }
SHA="$(sed -n 's/^construction_commit_sha:[[:space:]]*//p' "$RCP" | head -1)"
test -n "$SHA" || { echo RECEIPT_NO_SHA; exit 1; }
case "$SHA" in *[!0-9a-f]*) echo SHA_MALFORMED; exit 1;; esac
git cat-file -e "$SHA^{commit}" 2>/dev/null || { echo SHA_UNRESOLVED; exit 1; }
git -c core.quotepath=false diff-tree --no-commit-id --name-only -r --root "$SHA" | sort > "$W/actual.txt" || { echo DIFF_TREE_FAILED; exit 1; }
printf '%s\n' ".scratch/tickets/2026-11-07-SEMGOV-T1-技能包与契约票-v4.md" > "$W/declared.txt"
test -s "$W/declared.txt" || { echo DECLARED_EMPTY; exit 1; }
diff -u "$W/declared.txt" "$W/actual.txt" && echo DECL_SET_EQUAL
```

**三处高危点的改法（v3 在此必假红，逐条对应）**：

1. **回执路径**：v3 写 `.collab/receipts/SEMGOV-T1-v3.md`，落在本票 `deny_globs` 的 `.collab/**` 内——写不了，必假红。v4 改 `.scratch/tickets/2026-11-07-SEMGOV-T1-v4-receipt.md`，与 `deny_globs` 的全集（`docs/**`、`.archive/**`、`audits/**`、`.collab/**`、`agent-skills/**`、`agent-experts/**`、`softwares/**`、`*.py`）**无一相容冲突**。
2. **行首裸键**：真实回执若把键写成 `- construction_commit_sha:`、或缩进、或加引号，`sed` 抓不到。本脚本对三种写法均回 `RECEIPT_NO_SHA`（负样本 1／2 实测）。
3. **`core.quotepath`**：`git diff-tree` 默认对非 ASCII 路径做转义（`"\346\212\200..."`），与声明的中文路径永不相等。v4 用 `git -c core.quotepath=false diff-tree …`；另加 `--root`（root commit 不加时输出 0 行）。

5. **`40-provenance-map` 中 `1859aca` 的用法（主理人已裁，限制性允许）**：`spec_file` 可指它，但**不得表述为该登记含契约条款**。v4 落地为「`授权载体：1859aca＋本票`」双载体：`1859aca` 承担「本票口径经登记变更」这一**程序事实**，`本票` 承担「该条规则首在本票规定」这一**实质事实**，`条款正文：` 指到本包实际落点。**二者语义之别写死在此**：`1859aca` 是**条款来源载体**（该规则首在哪件规定），不是**变更授权载体**（谁批准本票改这部分）。`spec_file` 指向 `1859aca` 时，其含义仅为「口径变更的程序来源」，**不含任何条款正文**（该件第 2 节自明此点）。
6. **`R16`／`R17` 的编号合法性载体**：两号判据由主理人补登 `d1bb464` 另立登记（依 `1859aca` 第 2 节第 4 条），本票沿用。若审席要求严守 `R1–R15` 基数，则须由补登件先行撤销，再由本票降为附注——但那样「标识主表可解析」与「表头唯一性」就没有独立可指认编号，`N10` 与 `c06` 的机检归属也会失锚。**本票不自行降号**。
7. **黄3-11 三条业界出处离线不可核**：两席在审中均自标「不判缺陷」，本席同意并如实登记——本条要求的是离线可核，属审席自设的取证条件；三条名称（`obra/superpowers writing-skills`、`agentskills.io specification`、`claude.dev lessons-from-building`）在 `40-provenance-map.md` 表头第 1 组闭集中逐字落盘，当轮取证记录在案。若皮总要求离线留证，须另立取证票，不在本票范围。
8. **修3-11 二选一的取法与理由**：派工给的两条路线是「跨包继承规则」与「条款正文须指本包」。本版**取后者**，删去前者。理由：①「跨包继承规则」必然要求 `条款正文：` 指向跨包文件，与 `c18` 现成的「条款正文须指本包七件之一」断言直接冲突——两条同时存在就是语法互斥（这正是修3-11 的病根）；②若改 `c18` 去允许跨包指针，则「条款来源载体 ≠ 变更授权载体」的边界更难守住，且指针套指针会让「这条规则到底写在哪」在多包之间来回跳；③取「本包只登记承接点」后，条目 9 的落点是本包 `10-contract.md §2` 的「四件套承接条款」段，该段明写「正文由 `bundle:external-advisor-collab` 承担，本包只消费其结论」，跨包信息以「包名＋条款名」在承接条款处出现一次，不再进出处表。
9. **修3-15 二选一的取法与理由**：派工给的两条路线是「写实测正确版本」与「改不带版本号并说明」。本版**取后者**。理由：五个组件里只有两个可取证（`object-audit` frontmatter `version: 0.9`、`sop` frontmatter `version: 1.0.0`），另两个在本票出票时仓内无实体（`semantic-governance` 是 T2 交付物、`deep-research` 在仓内无对应目录），无法取证；写不出来的数字不能猜。且本包**不消费版本号**——钉死版本只会让 T2／T3 装配后任一方升级即把本包误判为红，错值还会被 T3 照抄继承。版本一致性归 T3 承担，判据 `c19` 只验形态 `^bundle:[a-z0-9-]+$` 与组件名闭集。
