| 时效 | `expiry` | `YYYY-MM-DD` 或 `none`；兼作批准有效期（同一主张的有效性与批准有效性同轴） | 必填 |
| 引用 | `linked_artifacts` | `<kind>:<value>` 列表，以 `;` 分隔；`kind` ∈ `source` / `cite` / `artifact` / `authorization` | 必填 |
| 可比对 | `assertion_form` | `qualitative` / `quantity` / `datetime` / `identifier` / `completeness` | 必填 |
| 可比对 | `comparability_ref` | `CMP-[0-9]{3,}` 或 `none`；`assertion_form ≠ qualitative` 时禁 `none` | 条件必填 |
| 主张时效 | `review_owner` | `<role-kind>:<ref>`；`status = frozen_assumption` 时禁 `none` | 条件必填 |
| 主张时效 | `reopen_trigger` | 一句可判的重开条件；`status = frozen_assumption` 时禁 `none` | 条件必填 |

**引用形态**：`source:` 后接 `INTK` / `RES` / `MSR` / `DOC` 前缀编号；`cite:` 后接同一前缀编号再跟 `#` 与条款位置或日期；`artifact:` 后接 `TKT` / `RCP` / `PRD` / `QAV` / `DLV` / `OUT` / `REQ` / `CMP` 前缀编号；`authorization:` 后接 `AUTH` / `DEC` 前缀编号。

**来源载体边界**：`INTK` 前缀只证明「该输入件来自何处、摘要为何」，不证明其内容为 `FACT`，也不证明其具 `binding` 权威。任何 `FACT` 或 `binding` 的成立须另行满足第 2 节相容矩阵与第 7 节硬规则。

**责任主体边界**：`requestee` 是请求对象，不得单独充当 `accountable_party`；`accountable_party ≠ none` 时 `responsibility_basis` 必须非 `none`，即责任主体必须挂来源或授权依据。

**字段裁撤记录**：主张行不设 `source_kind`（与 `source_layer` 语义重叠，R1–R17 中无判据消费其取值，已删）；不设 `approval_scope`（授权范围由 `authorization:` 所指 `DEC` 条目承载，本列无语义判据，已删）；不设 `verification_ref`（验证块以 `claim_id` 为主键挂在表 D，主张行无需再挂指针）。逐字段消费方对照见票面 §0.5。

## 2. 来源层判定序与相容矩阵

**来源层判定序（按序取首个命中，不得跳序）**：

1. 该主张的法定或监管依据可指认到外部强制规则 → `legal_regulatory`。
2. 该主张的约束来自已签署合同的条款 → `contractual`。
3. 该主张来自经批准并生效的基线件 → `approved_baseline`。
4. 该主张来自客户书面提出的要求 → `customer_request`。
5. 该主张来自本方技术设计决定 → `technical_design`。
6. 以上均不成立 → `internal_assumption`。

**判定序的落格要求**：判定为 1–4 层的，`responsibility_basis` 必须非 `none` 且指向可解析的 `source:` 或 `authorization:` 引用；1–4 层而无书面载体（如仅口头新要求）**不得**落入该层，按第 6 步归 `internal_assumption`，并在 `claim` 内注明「未成文」。

| `source_layer` | `binding` | `consultative` | `internal_only` | `unverified` |
|---|---|---|---|---|
| `legal_regulatory` | 条件 | 允许 | 禁止 | 允许 |
| `contractual` | 条件 | 允许 | 禁止 | 允许 |
| `approved_baseline` | 条件 | 允许 | 禁止 | 允许 |
| `customer_request` | 条件 | 允许 | 允许 | 允许 |
| `technical_design` | 禁止 | 禁止 | 允许 | 允许 |
| `internal_assumption` | 禁止 | 禁止 | 允许 | 允许 |

**「条件」的判据**：`approver` 形如 `human:<ref>`，且 `status` ∈ `accepted` / `external_pending` / `external_confirmed`，且 `expiry ≠ none`；`legal_regulatory` 与 `contractual` 另须 `linked_artifacts` 含至少一条 `cite:` 引用（外部引用四件套由 `bundle:external-advisor-collab@v1.1.3` 承担，本文件不复写四件套正文）。

**未在矩阵中出现的组合一律判违例**，不做默认放行。

## 3. 主张级验证登记（表 D）

验证块是**主张级**的：每条主张在表 D 有且仅有一行，主键 `claim_id`。表 D 是验证面的唯一登记处，主张行不重复承载验证字段。

| 字段 | 闭集／格式 | 填写归属 | 必填性 |
|---|---|---|---|
| `claim_id` | `C-[0-9]{3,}`；须在表 A 已登记 | 生产者 | 必填 |
| `original_requirement_ref` | `REQ-[0-9]{3,}` 或 `none`；指向表 C 的 REQ 行 | 需求侧 | 必填 |
| `required_environment` | `mock` / `test` / `integration` / `production` / `none` | 需求侧；生产者照录，QA 不得回写 | 必填 |
| `required_checks` | `functional` / `security` / `performance` / `compliance` / `robustness` 的子集，以 `;` 分隔，或 `none` | 同上；集合语义，非全序 | 必填 |
| `required_change_record` | `none`，或 `<原值>→<新值>@<approver>`；`<approver>` 须与本行 `approver` 同值 | 需求或生产者变更要求时 | 必填 |
| `actual_environment` | 同四值，另允许 `unverified` | 只由 QA 填 | 必填 |
| `actual_checks` | 同五值集合的子集，以 `;` 分隔，或 `none` | 只由 QA 填 | 必填 |
| `qa_result` | `pending` / `passed_at_actual` / `passed_with_exemption` / `failed` / `blocked` | 只由 QA 填 | 必填 |
| `exemption` | `none` / `partial` / `full` | 生产者申请、人类批准 | 必填 |
| `reason` | 一句可判理由 | `exemption ≠ none` 时 | 条件必填 |
| `scope` | 受限面描述 | `exemption ≠ none` 时 | 条件必填 |
| `fallback_criterion` | 一句可判的回退判据 | `exemption ≠ none` 时 | 条件必填 |
| `reopen_trigger` | 一句可判的重开条件 | `exemption ≠ none` 时 | 条件必填 |

**环境轴序位（全序，唯一参与大小比较的轴）**：`mock` = 1 ＜ `test` = 2 ＜ `integration` = 3 ＜ `production` = 4。`unverified` 不参与比较，出现即视为未达任何要求环境；`none` 表示未提出要求，不参与比较。

**检查轴（集合，不排序）**：`required_checks` 与 `actual_checks` 按集合包含关系判定，不做大小比较。

**同名双面字段**：`reopen_trigger` 在表 A（主张冻结的重开条件）与表 D（降级的重开条件）各有一面；同一 `claim_id` 两面均非 `none` 时必须同值（见 `30-gates` `R5` 第五支）。

## 4. 可比对断言（表 B）与受限抽取模式

**可比对断言登记表（表 B）列**：`cmp_id` / `cmp_key` / `cmp_kind` / `cmp_value` / `completeness_mode` / `enumeration_count` / `remaining_count` / `claim_id` / `source_artifact`。

- 表 B 是**可比对断言行**的唯一登记处。**「唯一」指表只有一处**，不是「每个键只有一行」：同一 `cmp_key` 可以有多行，各行的 `source_artifact` 指名该数值由哪份工件给出；同键多行即构成跨件比对点（见 `30-gates` `R11`）。
- `cmp_id` 格式 `CMP-[0-9]{3,}`；`cmp_kind` ∈ `quantity` / `datetime` / `identifier` / `completeness`，须与所引主张的 `assertion_form` 相同。
- `cmp_key` 是「同一可识别对象」的键；**触发比对以 `cmp_key` 相等为条件，不以任何可选字段是否填写为条件**。
- `cmp_value` 是该对象的取值：数量为数值；时点为 `YYYY-MM-DD` 或 `YYYY-MM-DDThh:mm`；标识为被引编号；完备性为 `resolved`。
- `identifier` 类断言的 `cmp_value` 必须在**标识与需求主表（表 C）**已登记，且其 `definition_ref` 非 `none`。
- `completeness` 类断言必须填 `completeness_mode` ∈ `cleared` / `partial`，且 `enumeration_count` ＞ 0；`cleared` 时 `remaining_count` 必须 ＝ 0，`partial` 时 `remaining_count` 必须 ＞ 0。其他 `cmp_kind` 三列均写 `none`。

**受限抽取模式（闭集，语境化：先有断言引导词，再有数值或时点）**

| 类 | 模式（正则片段） |
|---|---|
| 数量（阿拉伯） | `(剩余\|还剩\|还缺\|缺口\|共\|合计\|总计\|已\|待\|完成\|核销)\s*[0-9]+(\.[0-9]+)?\s*(人日\|人\|天\|小时\|分钟\|次\|个\|条\|项\|处\|万元\|元\|%)` |
| 数量（中文） | `(剩余\|还剩\|还缺\|缺口\|共\|合计\|总计\|已\|待\|完成\|核销)\s*[一二三四五六七八九十百千万两]+\s*(人日\|人\|天\|小时\|分钟\|次\|个\|条\|项\|处\|万元\|元\|成\|倍)` |
| 时点 | `(于\|截至\|截止\|止于\|完成于\|清零于\|定于\|在)\s*(20[0-9]{2}-[0-9]{2}-[0-9]{2}\|[0-9]{1,2}月[0-9]{1,2}日)` |
| 完备性 | `(清零\|一条不剩\|无遗漏\|核销完毕\|关闭完毕\|验收完毕)\s*(于\|之日\|为止\|完成)` |

**收窄依据（口径变更，取代上一版的裸量词触发）**：上一版把 `全部` / `所有` / `一律` / `均已` / `全覆盖` 作为完备性触发词，这些词在纪律性文本里高频出现（本文件自身就有三处），会把普通工作票系统性误判为完备性断言并逼出假计数。本版改为**引导词＋数值或时点**的语境化模式，裸量词不再触发；`c20` 用四例普通工作票正样本与四例真断言正样本双向实跑固定这一收窄。

**标识类不做抽取兜底**：标识形态（线号、表号、条目号）与治理语汇大量重名，正则抽取误报高于漏报代价；其覆盖改由「申报 `assertion_form=identifier` 即强制入表 ＋ 表 C 可解析」承担。

**标识与需求主表（表 C）列**：`id_key` / `id_value` / `definition_ref` / `status` / `req_required_environment` / `req_required_checks` / `req_enumeration_base`。

- 表 C 同时承担两件事：**标识定义**（`id_key`／`id_value`／`definition_ref`／`status`）与 **原始需求的要求面**（`req_*` 三列）。二者共用一张表是因为 REQ 条目本身就是一种标识；分两张表会产生两处 `REQ-` 编号真源。
- `id_value` 是编号本体，`REQ-` 起头的行即「原始需求条目」；`id_key` 是分类键（如「线号」「表号」「需求」）。
- `status` ∈ `defined` / `draft` / `retired`；`status ≠ defined` 的 `id_value` 不得被任何主张引用。
- `req_required_environment` ∈ 环境轴四值或 `none`；`req_required_checks` ∈ 检查轴五值子集（以 `;` 分隔）或 `none`；`req_enumeration_base` 为非负整数或 `none`（该需求的原始枚举基数）。
- 非 `REQ-` 行的三列 `req_*` 一律写 `none`。

## 7. 状态语义硬规则

1. `accepted` 不等于 `external_confirmed`；内部接受不得写成外部确认。
2. `frozen_assumption` 只限内部：`expiry`、`review_owner`、`reopen_trigger` 三者均不得为 `none`，`expiry=none` 直接判违例；不得外溢为默认认可。
3. `external_pending` 超时只触发复核与升级，不自动变为 `external_confirmed`。
4. `external_effect=outbound_authorized` 只能由人类闸设置。
5. `superseded` 保留旧行，不删除、不改写；被 `superseded` 的主张不得再被任何工件引用。
6. QA 按 `actual_environment` / `actual_checks` 判定通过，不回写 `required_environment` / `required_checks`。
7. `evidence_tag` 为 `UNKNOWN` 或 `STALE` 时，`status` 不得为 `accepted`，`authority` 不得为 `binding`，`external_effect` 不得为 `outbound_authorized`。

## 3. 交付汇总聚合字段（七桶＋分母，互斥且完备）

七个桶**互斥**，且必须**完备**——即七桶之和恒等于 `total_claims`。分桶按下列判定序取首个命中，不得跳序、不得重复计入：

1. `qa_result ∈ {failed, blocked}` → 计入 `failed`。
2. `actual_environment = unverified` → 计入 `unverified`。
3. `qa_result = passed_with_exemption` → 计入 `excluded_by_approval`。
4. `actual_environment = production` 且 `qa_result = passed_at_actual` → 计入 `real_env_passed`。
5. `actual_environment ∈ {mock, test, integration}` → 计入 `mock_only`。
6. `actual_environment = production` 且 `qa_result = pending` → 计入 `pending`。
7. 其余（含 `required_environment = none` 的主张）→ 计入 `not_required`。

| 字段 | 语义 |
|---|---|
| `total_claims` | 本次交付涉及的、在表 D 已登记的主张总数（分母＝表 D 行数） |

def pkg_read(pkg, rel):
    with open(os.path.join(pkg, rel), encoding="utf-8") as f:
        return f.read()


def pkg_write(pkg, rel, text):
    with open(os.path.join(pkg, rel), "w", encoding="utf-8", newline="\n") as f:
        f.write(text)


def pkg_swap_words(pkg, rel, a, b):
    t = pkg_read(pkg, rel)
    if a not in t or b not in t:

    t = t.replace(a, "\x00").replace(b, a).replace("\x00", b)
    pkg_write(pkg, rel, t)


def pkg_swap_fm(pkg, rel):
    t = pkg_read(pkg, rel)
    n = re.search(r"^name://s*(//S+)//s*$", t, re.M)
    v = re.search(r"^version://s*(//S+)//s*$", t, re.M)
    if not n or not v:
        raise Red("结构变异锚不存在")
    t = t.replace(n.group(0), "name: " + v.group(1)).replace(v.group(0), "version: " + n.group(1))
    pkg_write(pkg, rel, t)


def pkg_swap_header(pkg, rel, ncols, ca, cb):
    t = pkg_read(pkg, rel)
    lines = t.split("\n")
    for i, l in enumerate(lines):
        if not l.strip().startswith("|"):
            continue
        cells = [c.replace("`", "") for c in split_row(l)]
        if len(cells) == ncols and ca in cells and cb in cells:
            a, b = cells.index(ca), cells.index(cb)
            cells[a], cells[b] = cells[b], cells[a]
            lines[i] = "| " + " | ".join(cells) + " |"
            pkg_write(pkg, rel, "\n".join(lines))
            return
    raise Red("结构变异锚不存在")


def pkg_mkdir(pkg, rel):
    os.makedirs(os.path.join(pkg, rel), exist_ok=True)


def pkg_rename(pkg, a, b):
    if not os.path.exists(os.path.join(pkg, a)):
        raise Red("结构变异锚不存在")
    os.rename(os.path.join(pkg, a), os.path.join(pkg, b))


def pkg_dropprefix(pkg, rel, prefix):
    lines = pkg_read(pkg, rel).split("\n")
    if not any(l.startswith(prefix) for l in lines):
        raise Red("结构变异锚不存在")
    pkg_write(pkg, rel, "\n".join(l for l in lines if not l.startswith(prefix)))

# ---------------------------------------------------------------- 变异算子
def mut_del(text, loc):
    return apply_loc(text, loc, "")


def mut_rev(text, loc):
    return apply_loc(text, loc, reverse_text(extract_loc(text, loc)))


def mut_pad(text, loc):
    return apply_loc(text, loc, extract_loc(text, loc) + " 补充说明见附注。")


def mut_sub(text, old, new, count=0):
    if old not in text:
        raise NotHere(old[:40])
    return text.replace(old, new) if count == 0 else text.replace(old, new, count)


def mut_sub_all_rows(text, ncols, start, col, old, new):
    lines = text.replace("\r\n", "\n").split("\n")
    off = None
    for i, l in enumerate(lines):
        if l.strip() == start:
            off = i
            break
    if off is None:
        raise NotHere(start)
    hit = 0
    for i in range(off, len(lines)):
        if not lines[i].strip().startswith("|"):
            if hit:
                break
            continue
        cells = split_row(lines[i])
        if len(cells) != ncols or all(re.fullmatch(r"[:\- ]*", c) for c in cells):
            continue
        if col < len(cells) and cells[col] == old:
            cells[col] = new
            lines[i] = "| " + " | ".join(cells) + " |"
            hit += 1
    if not hit:
        raise NotHere(old)
    return "\n".join(lines)

def run_mutations(pkg):
    base = os.path.abspath(pkg)
    ok = 0
    failed = []
    muts = []
    for item in build_mutations():
        if len(item) == 3:
            cid, name, fn = item
            key = None
        else:
            cid, name, fn, key = item
        muts.append((cid, name, key, fn))
    for e in EXPECT_TARGETS:
        muts.append((e["check"], "OP-del %s 删值" % e["id"], e["key"], (lambda t, e=e: mut_del(t, e["loc"]))))
        muts.append((e["check"], "OP-rev %s 等长反义" % e["id"], e["key"], (lambda t, e=e: mut_rev(t, e["loc"]))))
        muts.append((e["check"], "OP-pad %s 加噪" % e["id"], e["key"], (lambda t, e=e: mut_pad(t, e["loc"]))))

    per = {}
    for cid, name, fn in PKG_MUT:
        tmp = tempfile.mkdtemp(prefix="semgov-pkgmut-")
        dst = os.path.join(tmp, os.path.basename(base))
        shutil.copytree(base, dst)
        try:
            fn(dst)
            out = run_check(cid, dst)
            failed.append((cid, name, "假通过（变异后仍报 %s）" % out))
            per.setdefault(cid, [0, 0])[1] += 1
        except Red as exc:
            print("FAIL %-4s %-52s -> %s" % (cid, name, str(exc)[:88]))
            ok += 1
            per.setdefault(cid, [0, 0])[0] += 1
        finally:
            shutil.rmtree(tmp, ignore_errors=True)
    for cid, name, key, fn in muts:
        done = False
        for rel in ([KEY_INV[key]] if key else FILES):
            src = os.path.join(base, rel)
            with open(src, encoding="utf-8") as f:
                orig = f.read()
            try:
                new = fn(orig)
            except NotHere:
                continue
            except Red as exc:
                failed.append((cid, name, str(exc)))
                done = True
                break
            if new == orig:
                continue
            tmp = tempfile.mkdtemp(prefix="semgov-mut-")
            dst = os.path.join(tmp, os.path.basename(base))
            shutil.copytree(base, dst)
            with open(os.path.join(dst, rel), "w", encoding="utf-8", newline="\n") as f:
                f.write(new)
            try:
                out = run_check(cid, dst)
                failed.append((cid, name, "假通过（变异后仍报 %s）" % out))
                per.setdefault(cid, [0, 0])[1] += 1
            except Red as exc:
                print("FAIL %-4s %-52s -> %s" % (cid, name, str(exc)[:88]))
                ok += 1
                per.setdefault(cid, [0, 0])[0] += 1
            finally:
                shutil.rmtree(tmp, ignore_errors=True)
            done = True
            break
        if not done:
            failed.append((cid, name, "MUTATE-FAILED 变异未产生任何变化"))
            per.setdefault(cid, [0, 0])[1] += 1
    print("")
    for cid, name, why in failed:
        print("!! %-4s %-52s -> %s" % (cid, name, why))
    print("变异体合计 %d 条（结构面 %d ＋ 内容面 %d）：变红 %d 条，异常 %d 条"
          % (len(muts) + len(PKG_MUT), len(PKG_MUT), len(muts), ok, len(failed)))
    ids = sorted(per)
    print("逐判据覆盖：" + " ".join("%s=%d/%d" % (c, per[c][0], per[c][0] + per[c][1]) for c in ids))
    covered = [c for c in ids if per[c][0] > 0]
    miss = [c for c, _t, _f in CHECKS if c not in covered]

def main(argv):
    if len(argv) < 2:
        print(__doc__)
        return 2
    if argv[1] == "--list":
        for c, t, _ in CHECKS:
            print("%-4s %s" % (c, t))
        return 0
    if argv[1] == "--all":
        pkg = argv[2]
        bad = 0
        for c, t, fn in CHECKS:
            try:
                msg = fn(pkg)
                print("OK   %-4s %s" % (c, msg))
            except Red as exc:
                bad += 1
                print("FAIL %-4s %s" % (c, exc))
        return 0 if bad == 0 else 1
    if argv[1] == "--mutate":
        return run_mutations(argv[2])
    if len(argv) < 3:
        print("用法：verify.py <check-id> <pkg-dir>")
        return 2
    try:
        msg = run_check(argv[1], argv[2])
        print("OK   %-4s %s" % (argv[1], msg))
        return 0
    except Red as exc:
        print("FAIL %-4s %s" % (argv[1], exc))

## 3.13 SHA 对账（`set -o pipefail`，防 `git diff-tree` 失败被 `sort` 吞掉）

```bash
set -o pipefail
W="$(mktemp -d)"
SHA="$(sed -n 's/^construction_commit_sha:[[:space:]]*//p' .collab/receipts/SEMGOV-T1-v3.md | head -1)"
test -n "$SHA" || { echo RECEIPT_NO_SHA; exit 1; }
case "$SHA" in *"$'\n'"*) echo SHA_MULTILINE; exit 1;; esac
git diff-tree --no-commit-id --name-only -r --root "$SHA" | sort > "$W/actual.txt" || { echo DIFF_TREE_FAILED; exit 1; }
cat > "$W/declared.txt" <<'EOF'
.scratch/tickets/2026-11-07-SEMGOV-T1-技能包与契约票-v3.md
EOF
sort -o "$W/declared.txt" "$W/declared.txt"
test -s "$W/declared.txt" || { echo DECLARED_EMPTY; exit 1; }
diff -u "$W/declared.txt" "$W/actual.txt" && echo DECL_SET_EQUAL
```

**回执键格式钉死（黄2-11）**：`construction_commit_sha:` 必须是**行首裸键**——不得写成 `- construction_commit_sha:`、不得缩进、不得加引号；否则 `sed` 抓不到，脚本回 `RECEIPT_NO_SHA`。`--root` 参数不可省：组件作为根提交时 `git diff-tree` 不加 `--root` 输出 0 行（v2 已实测 0 行 vs 7 行），省掉会假红。
