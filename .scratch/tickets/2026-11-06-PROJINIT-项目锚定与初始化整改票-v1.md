## 一、背景与依据

### 1.1 真实用途与现行为缺陷（时序倒置）

百工软件团队专家团（`agent-experts/baigong-software-team/`）装配部署后的真实用途＝**开发其他业务项目**，而非维护专家团自己。现行为存在时序倒置缺陷：

- 探针序（起草实测四脚本逐字同款：write-guard.py L48–76／lease-issuer.py L32–60／commit-audit.py L56–84／memory-neutralize.py L44–72）＝
  ① `SWB_REPO_ROOT` 环境变量覆写（现 docstring 自认「测试重定向」）；
  ② 自 cwd 上溯首个含 `docs/STRUCTURE.md` 且 ≠ 包根的目录＝项目根；
  ③ 缺位回退自包根上溯（同样跳过包根自身）；
  ④ 全缺位＝落回包根（fail-safe·deny 不开 fail-open）。
- ②/③ 序以「**宿主项目已存在 `docs/STRUCTURE.md` 锚点**」为判定前提。真实次序＝部署专家团 → 进入空白新项目 → 该项目恰由专家团进场建档：进场时刻该项目**必然没有** `docs/STRUCTURE.md`（该件本身是建档步产物）。
- 后果链：探针 ②③ 双双落空 → ④ 兜底落包根（装配/部署态＝平台缓存目录）→ 权限面（`config/seat-permissions*.json` deny/write_globs 项目根字面）、租约面（`default_ledger_root()＝<project_root()>/.collab/ledger`）、提交审计、memory 中立化**四链全锚错处**＝账本/租约/权限面整体错位。

### 1.2 决策者裁定口径（票面据此转述为决策依据·2026-11-06）

1. 「首先是锚定用户指定的项目根和部署根，然后在项目根下创建专家团规范的项目内部路径。」
2. 「`docs\STRUCTURE.md` 应该是专家团按规范提示给用户的，而不能默认用户会按我们的规范去提前准备好一切工序。」
3. 用户可指定任意自由形式的结构说明（如 `xxx.md` 甚至 `xxx.txt`）；专家团须把这份结构**誊录 → 规范校验通过后 → 迁移落笔到 `docs/STRUCTURE.md`**；`docs/` 不是用户写入路径（人类行为在机械面上不受 hooks 限制），`docs/` 是专家团按席位规范的写路径；只能引导用户，不能强制用户。
4. 总纲：「`docs/STRUCTURE.md` 和其他目录、交接件、交付件规范一样，同属于专家团自己的治理规范，而不是对人类用户的约束，永远不可能约束用户，只能配合用户」——**一切机制设计不得以「用户预置合规件」为前提**。

## 三、实装规格（写死·可机械验证·行位以开工实测为准）

### 3.1 落点一～四：四脚本 `project_root()` 换代（四脚本逐字同款·GWP 红线随迁）

**替换对象**（逐字锚文·四脚本整段＝`def project_root()` 起 def＋docstring＋函数体）：

- write-guard.py L48–76／lease-issuer.py L32–60／commit-audit.py L56–84／memory-neutralize.py L44–72——起草实测四段**逐字相同**（首行 `def project_root() -> str:`、docstring 首句 `"""GWP-P1-1 探针序换代：① SWB_REPO_ROOT＝项目根覆写面（测试重定向·覆写语义零动）；`、末两行 `        d = parent` / `    return pack`）。

**替换为**（四脚本逐字相同·含常量与两个 helper 前置）：

```python
ANCHOR_FILE = os.path.join(".workbuddy", "swb-anchor")  # PROJINIT-P1 显式锚定声明件（项目根相对字面·四脚本同款）


def _anchor_hit(d: str, pack: str) -> bool:
    """显式锚定命中：d≠包根 ∧ d/.workbuddy/swb-anchor 存在 ∧ 首个 `project_root:` 行解析值
    （相对值按 d 解析）经 normcase 后＝d 自身（自指闭合＝锚件不得指向他处，防跨项目劫持）。"""
    if os.path.normcase(d) == os.path.normcase(pack):
        return False
    ap = os.path.join(d, ANCHOR_FILE)
    if not os.path.isfile(ap):
        return False
    try:
        with open(ap, encoding="utf-8") as f:
            text = f.read()
    except OSError:
        return False
    for line in text.splitlines():
        if line.strip().startswith("project_root:"):
            val = line.split(":", 1)[1].strip().strip("\"'")
            if not val:
                return False
            target = val if os.path.isabs(val) else os.path.join(d, val)
            return os.path.normcase(os.path.abspath(target)) == os.path.normcase(d)
    return False


def _structure_hit(d: str, pack: str) -> bool:
    """事后校验路：d≠包根 ∧ d/docs/STRUCTURE.md 存在（旧 ②③ 文件溯源语义降档保持·不再作判定前提）。"""
    return (os.path.normcase(d) != os.path.normcase(pack)
            and os.path.isfile(os.path.join(d, "docs", "STRUCTURE.md")))


def project_root() -> str:
    """PROJINIT-P1 锚定换代（决策者裁定①：先锚定用户指定的项目根/部署根）：
    ① SWB_REPO_ROOT＝显式覆写面（测试重定向＋部署态正式锚定·覆写语义零动）；
    ② 自 cwd 上溯首个 `.workbuddy/swb-anchor` 显式锚定命中目录＝项目根（权威锚·进场建档步落笔）；
    ③ 自 cwd 上溯首个含 `docs/STRUCTURE.md` 且≠包根目录（事后校验路·降档保持·命中包根即跳过）；
    ④ 缺位回退自包根上溯（②③ 同款两路，同样跳过包根自身）；
    ⑤ 全缺位＝落回包根（fail-safe·权限面读空即租约不命中＝deny，不开 fail-open 窗口——旧语义保持）。
    权限字面一律读作项目根相对（表2-1 路径锚定款随迁）。"""
    env = os.environ.get("SWB_REPO_ROOT")
    if env:
        return env
    pack = pack_root()
    for probe in (_anchor_hit, _structure_hit):
        for d0 in (os.getcwd(), os.path.dirname(pack)):
            d = d0
            while True:
                if probe(d, pack):
                    return d
                parent = os.path.dirname(d)
                if parent == d:
                    break
                d = parent
    return pack
```

**条款写死**：

1. **显式锚定双路**＝(a) `SWB_REPO_ROOT` 环境变量：语义由「测试重定向面」**转正为部署态正式锚定机制之一**，覆写行为零动；(b) 锚定声明件 `<项目根>/.workbuddy/swb-anchor`——单文件、UTF-8、至少含一行 `project_root: .`（自指闭合校验见 `_anchor_hit`；亦可写绝对值，校验同规）。两路同在时 **(a) 覆写优先**。
2. **权威优先级**＝环境变量覆写 ＞ 锚定声明件 ＞ STRUCTURE.md 文件溯源。锚定件与 STRUCTURE.md **均缺席**＝落 ④ 包根 fail-safe（裁定④：不得以用户预置件为前提，故建档前无锚＝无 allow 通道＝deny，纪律不破）。
3. **写入者（席位）**＝锚定声明件由**主理人（host）经当票租约**在进场建档步落笔（host `write_globs` 现不含 `.workbuddy/`＝需票内临时豁免域租约或 config 随批改文，**两案候裁 H-1**）；任何机械席位不得在锚定件上改写既有锚值（改锚＝重开建档步经主理人）。
4. **读取者**＝四脚本（write-guard／lease-issuer／commit-audit／memory-neutralize），`project_root()`＋`_anchor_hit`＋`_structure_hit`＋`ANCHOR_FILE` 四段**逐字同款**（GWP 先例 commit `5b8936e` 红线延续·脚本自包含分发形制保持·无跨件 import）。
5. **落位写死**＝锚定声明件字面 `.workbuddy/swb-anchor`（项目根相对·顶层点号面不入 STRUCTURE 声明射程＝既成惯例，见包 `docs/STRUCTURE.md` 末段注）。四区归属：锚定件属 `.collab/`-同级的**装配锚位面**，不入 `sources/`（唯一事实源禁解析件）、不入 `docs/`。
6. **`default_ledger_root()` 零动**（GWP 已统一＝随 `project_root()` 自动随迁至锚定根＝本批改锚的账本面收益，无需改码）。
