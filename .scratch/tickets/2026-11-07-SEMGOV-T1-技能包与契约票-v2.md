# claim-commitment-governance · 主张—承诺治理

**定位**：本技能只在构建期提供「主张—来源—责任—验证—外发」五段语义契约；不替代 deep-research 的调研，不替代 object-audit 的审计，不执行任何业务判断，不建完整催办台账（需要完整台账时另案立项）。

## 触发与不触发

**该触发（正路由样例）**

1. 「给这份 PRD 的主张标来源层与证据标签」→ 触发。
2. 「这张工作票要填验证环境、检查维度与降级豁免」→ 触发。
3. 「这封对外函件发出去前过事实审查、承诺审查与授权」→ 触发。
4. 「交付汇总里哪些只是 Mock、哪些没验」→ 触发。

**不该触发（负路由样例）**

1. 「把这个函数改成异步」→ 不触发（纯代码实现，无主张与承诺）。
2. 「把这份表格的行距调一下」→ 不触发（纯排版）。
3. 「现在几点」→ 不触发（无主张无承诺的事实快答）。
4. 「这份调研的证据链怎么补」→ 不触发（调研本体归 deep-research，本技能只在成文时消费其证据标签）。

6. 替代实现、占位、降级必须写明要求环境与检查、实际环境与检查、豁免与回退判据。

| `scope` | 受限面描述 | `exemption ≠ none` 时必填 |
| `fallback_criterion` | 一句可判的回退判据 | 降级必填 |
| `reopen_trigger` | 一句可判的重开条件 | 降级必填 |
| `qa_result` | `pending` / `passed_at_actual` / `passed_with_exemption` / `failed` / `blocked` | 只由 QA 填 |

**环境轴序位（全序，唯一参与比较的轴）**：`mock` = 1 ＜ `test` = 2 ＜ `integration` = 3 ＜ `production` = 4。`unverified` 不参与比较，出现即视为未达任何要求环境。

**检查轴（集合，不排序）**：`required_checks` 与 `actual_checks` 按集合包含关系判定，不做大小比较。

## 4. 可比对断言与完备性计数

**可比对断言登记表（`templates/claim-register.md` 表 B）列**：`cmp_id` / `cmp_key` / `cmp_kind` / `cmp_value` / `enumeration_count` / `remaining_count` / `claim_id` / `source_artifact`。

- `cmp_id` 格式 `CMP-[0-9]{3,}`；`cmp_kind` ∈ `quantity` / `datetime` / `identifier` / `completeness`，须与所引主张的 `assertion_form` 相同。
- `cmp_key` 是「同一可识别对象」的键；**跨件比对以 `cmp_key` 相等为触发条件，不以任何可选字段是否填写为条件**。
- `cmp_value` 是该对象的取值（数量为数值，时点为 `YYYY-MM-DD` 或 `YYYY-MM-DDThh:mm`，标识为被引编号，完备性为 `resolved`）。
- `identifier` 类断言的 `cmp_value` 必须在**标识主表（表 C）**中已登记，且其 `definition_ref` 非 `none`。
- `completeness` 类断言必须同时填 `enumeration_count`（枚举依据条数，须 ＞ 0）与 `remaining_count`（未决剩余数，清零类须 ＝ 0）；其他 `cmp_kind` 两列均写 `none`。

**受限抽取模式（闭集，用于兜底判定；只覆盖三类低误报模式）**

| 类 | 模式 |
|---|---|
| 数量 | `[0-9]+(\.[0-9]+)?\s*(人日\|人\|天\|小时\|分钟\|次\|个\|条\|项\|处\|万元\|元\|%)` |
| 中文数量 | `[一二三四五六七八九十百千万两]+(人日\|人\|天\|小时\|分钟\|次\|个\|条\|项\|处\|万元\|元\|成\|倍)` |
| 时点 | `[0-9]{4}-[0-9]{2}-[0-9]{2}` 或 `[0-9]{1,2}月[0-9]{1,2}日` 或 `[0-9]{1,2}:[0-9]{2}` |
| 完备性 | `清零\|全部\|所有\|无遗漏\|完备\|全覆盖\|均已\|一律\|一条不剩` |

**标识类不做抽取兜底**：标识形态（线号、表号、条目号）与治理语汇大量重名，正则抽取误报高于漏报代价；其覆盖改由「申报 `assertion_form=identifier` 即强制入表 ＋ 标识主表可解析」承担。

## 5. 强断言词表与占位词表

| 类别 | 闭集 |
|---|---|
| 强断言 | `必须` / `一律` / `全部` / `绝不` / `保证` / `确保` / `均已` / `全覆盖` |
| 占位词 | `待定` / `暂定` / `待补` / `TBD` / `TODO` / `待确认` / `placeholder` / `〔` |

`〔` 是模板填空标记；外发件在 `send_channel=approved_send` 时不得残留任一占位词或任一未替换的 `〔`。

## 7. 状态语义硬规则

1. `accepted` 不等于 `external_confirmed`；内部接受不得写成外部确认。

3. `external_pending` 超时只触发复核与升级，**不自动**变为 `external_confirmed`。
4. `external_effect=outbound_authorized` **只能**由人类闸设置。
5. `superseded` 保留旧行，不删除、不改写；被 `superseded` 的主张不得再被任何工件引用。
6. QA 按 `actual_environment` / `actual_checks` 判定通过，**不回写** `required_environment` / `required_checks`。
7. `evidence_tag` 为 `UNKNOWN` 或 `STALE` 时，`status` 不得为 `accepted`，`external_effect` 不得为 `outbound_authorized`。

5. 法律、合同或责任解释。
6. 外发动作本身。
7. 是否将沉默视为认可；**默认一律不算**。

def read(pkg, rel):
    path = os.path.join(pkg, rel)
    if not os.path.isfile(path):
        raise Red("缺件 %s" % rel)
    with open(path, "r", encoding="utf-8", newline="") as fh:

def lines_of(pkg, rel):

def section(lines, prefix):
    start = None
    level = 0
    for i, ln in enumerate(lines):
        if ln.startswith(prefix):
            start = i
            level = len(ln) - len(ln.lstrip("#"))
            break
    if start is None:
        raise Red("找不到章节 %r" % prefix)
    body = []
    for ln in lines[start + 1:]:
        s = ln.strip()
        if s.startswith("#"):
            lv = len(s) - len(s.lstrip("#"))
            if lv <= level:
                break
        body.append(ln)
    return body


def tables(sec):
    out, cur = [], []
    for ln in sec:
        if ln.strip().startswith("|"):
            cur.append(ln.strip())
        else:
            if cur:
                out.append(cur)
                cur = []
    if cur:
        out.append(cur)
    parsed = []
    for t in out:
        rows = []
        for row in t:
            cells = [c.strip() for c in row.strip("|").split("|")]
            if all(re.fullmatch(r":?-{2,}:?", c) for c in cells):
                continue
            rows.append(cells)
        if rows:
            parsed.append(rows)
    return parsed


def first_table(sec, what):

def backticks(cell):

def frontmatter(lines):
    if not lines or lines[0].strip() != "---":
        raise Red("frontmatter 缺失")
    fields = {}
    key = None
    for raw in lines[1:]:
        if raw.strip() == "---":
            break
        m = re.match(r"^([A-Za-z_][A-Za-z0-9_-]*):\s*(.*)$", raw)
        if m:
            key = m.group(1)
            fields[key] = m.group(2).strip()
        elif key and (raw.startswith(" ") or raw.startswith("\t")):
            fields[key] = (fields.get(key, "") + " " + raw.strip()).strip()
    return fields

def _sub(pkg, rel, old, new, count=1):
    path = os.path.join(pkg, rel)
    with open(path, "r", encoding="utf-8", newline="") as fh:
        text = fh.read()
    if old not in text:
        raise Red("变异锚不存在于 %s：%r" % (rel, old[:30]))
    text = text.replace(old, new, count)
    with open(path, "w", encoding="utf-8", newline="") as fh:
        fh.write(text)


def _line(pkg, rel, prefix, new):
    path = os.path.join(pkg, rel)
    with open(path, "r", encoding="utf-8", newline="") as fh:
        rows = fh.read().replace("\r\n", "\n").split("\n")
    hit = 0
    for i, row in enumerate(rows):
        if row.startswith(prefix):
            rows[i] = new
            hit += 1
    if hit != 1:
        raise Red("整行替换锚 %r 命中 %d 次（须恰 1）" % (prefix, hit))
    with open(path, "w", encoding="utf-8", newline="") as fh:
        fh.write("\n".join(rows))
