# 术语闭集与指针清单

> **用法**：本件是本包的**术语定义面**与**指针总表**。术语在主文件与分件里一律按本表词义使用，不得另立同义写法。

## 一、术语闭集

| 术语 | 定义 | 不得混用的相邻概念 |
|---|---|---|
| **索引件** | 描述「包由哪些组件、从哪个仓、按哪个 ref、取哪个路径、落到装配面哪里」的锁文件 | 组件清单（索引件带 ref 与解析结果，清单不带） |
| **装配面** | 装配器产出的、组件已就位的可注册包目录（在源仓之外） | 产地（装配面是产物，不是任何仓的工作区） |
| **部署面** | 平台侧实际加载的插件缓存目录（含版本层） | 工作空间（部署面是落地点，不在此编辑） |
| **装配全账** | 装配面内的机器可读全账：包版本、各组件 ref 与解析 commit、文件计数 | 同步账本（全账记「这次装了什么」，账本记「同步到哪一块」） |
| **同步账本** | 装配面内的追加式指纹流水（体例真源＝`object-build/references/60-publish.md`，指针） | 同上 |
| **组件** | 索引件里的一行：一个可独立取源的目录子树 | 包成员文件（组件是装配的输入单元，不是落盘后的散文件） |
| **漂移** | 装配面／部署面现字节与账本记录不等 ⇒ 违例，须停手（处置口径见 `object-build/references/60-publish.md`，指针） | 合法待同步（源侧先进、副本未跟上，不是违例，处置＝重同步） |
| **幂等短路** | 新账与末块账一致 ⇒ 零写入、不追加空块 | 跳过校验（幂等仍跑完全部前置与比对，只是不写） |
| **注册** | 装配面 → 部署面版本目录的整体复制替换 | 增量同步／合并／反向同步 |
| **平台侧重注册** | 把装配面当新包交给平台注册／更新，由平台完成落地与缓存切换 | 直接覆盖缓存目录（备选路径，风险更高） |

## 三、出处标注（每条规则的三档出处之一）

| 规则 | 出处档 | 说明 |
|---|---|---|
| 组件锁不可变 tag 或 commit、不用 HEAD／分支名 | 命名范式（语义化版本 SemVer 2.0 的不可变版本引用惯例） | 业界范式＋本地取值 |
| 按内容寻址记账（指纹逐文件记、只追加不改写） | 业界范式（内容寻址存储／追加式账本） | 业界通识 |
| 平台组件层跨仓取源的三条限制 | 本地约定（显式标注） | 实测所得，非引自文档 |
| 自研装配（仓外产出可注册包目录） | 本地约定（显式标注） | 对上述限制的工程应对 |
| 产物不入任何仓版本库、不可手改 | 本地约定（显式标注） | 派生自「部署面不是工作空间」的定性 |
| 先断言、后记账（顺序本身是判据） | 本地约定（显式标注） | 与发布器同款顺序，真源见上表指针 |
| 注册＝整体复制替换，非增量非合并 | 本地约定（显式标注） | 由「单向」这一定义性约束推出 |
| 判据须可机检、禁「合格／合理／完善」类词 | 本地约定（显式标注） | 与审计器可测性要求同源 |
| 三态口径（绿／未绿／已移出不计绿） | 本地约定（显式标注） | 沿用协作纪律的三态计数 |
