# fuxi-skill · rejected 留档区约定（README）

> 性质＝交付件约定面（自包含成文）。本区＝淘汰候选留档基面：未通过候选保持可审计＝产品线纪律面组成部分，与契约文件同根、同一版本受控。
> 记法：EG/FM/AC-<n>＝同域契约文件节号（`../contracts/`）；ST/FC/BW/GS-<n>＝断言目录编号（`../gates/assertion-catalog.md`）。正文零过程域指针。

## 一、目录约定

```
rejected/
  <batch-id>/                 ← 每蒸馏批次一目录（batch-id 命名＝日期-对象编号 kebab）
    <candidate-id>.md         ← 每条淘汰候选一个条目文件（candidate_id 与 EG-5 一致）
    coverage-audit.md         ← 每批次恰一份审计件
```

- 本目录本身必须存在（批次为零时允许空目录）＝ST-5「可枚举」的机械基面：目录存在＋条目可列；空 listing 是合法的可枚举态（断言工具按此语义实现）。
- 在选候选不落本区，其记录以 EG-5 候选单元记录形态嵌于批次工作件；淘汰动作＝候选条目落入本区批次目录＋coverage-audit 计数更新，两步同一提交（版本受控）。

## 二、条目文件字段（淘汰条目）

条目文件机读块字段名声明位（断言工具读本块与 FC-2 注册表双向对账）：

```json
{"字段注册": ["candidate_id", "所属轨", "淘汰维度", "淘汰理由", "证据等级", "control_arm", "leakage_check"]}
```

```json
{"值注册": {"candidate_id": ["string"], "所属轨": ["person", "method"], "淘汰维度": ["跨领域复现", "预测力", "排他性", "跨段落佐证", "可执行性", "任务效用"], "淘汰理由": ["string"], "证据等级": ["原文可证实", "跨文本推断", "模型补全"], "control_arm": ["三臂", "无臂", "未测"], "leakage_check": ["已检-不在语料内", "已检-在语料内", "未检"]}}
```

- 上列字段全部必须在场非空（「三问」字段 `证据等级`／`control_arm`／`leakage_check` 继承 EG-4 口径——淘汰条目同样可答三问，保证「未通过候选保持可审计」是可答的而非仅可看的）。
- `淘汰维度`＝本轨判定维度名（person 轨白名单＝跨领域复现／预测力／排他性；method 轨白名单＝跨段落佐证／可执行性／任务效用——判定维度分轨，框架共用）。
- `淘汰理由`＝自由文本非空＋不得含 FM-2 不确定措辞（「视情况」「酌情」「后续再定」类，子串扫描命中即 fail）。

示例条目（机读块·工具按注册表验字段名与三问在场）：

```json
{"candidate_id": "c-0042", "所属轨": "person", "淘汰维度": "排他性", "淘汰理由": "该启发式在相邻三例中均可由更简假设替代，无排他性证据",
 "证据等级": "跨文本推断", "control_arm": "无臂", "leakage_check": "未检"}
```

## 三、coverage-audit 审计件

每批次恰一份 coverage-audit.md（审计件文件名固定），恰含三问字段（字段名逐字＝ST-5 注册名）：

```json
{"字段注册": ["哪些留下", "哪些扔了", "为什么", "一手占比"]}
```

- `哪些留下`／`哪些扔了`／`为什么` 三字段齐备非空。
- 审计件同时登记 `一手占比` 读数行（承 EG-6 门槛）。
- 计数类数字受 BW-3 裸数字规则管辖（行级三件套扫描：统计口径＋样本量＋一致性系数）。
