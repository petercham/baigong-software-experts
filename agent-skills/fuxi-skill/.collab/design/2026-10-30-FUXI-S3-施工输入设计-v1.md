## 一、source-anchor validator（method 轨硬门）规格

### 1.1 层结构（顺序执行，前层 fail 不进后层；层名即 gate_source 注册词）

| 层 | 层名（gate_source 取值） | 内容 | 条款 |
|---|---|---|---|

| L3 | `诱饵测试` | 近邻卡 decoy 对照：与产物卡同问题域但不应触发的近邻卡混入触发题库；命中数>0＝FM-M-01/03 处置。method 轨近邻定义（补前置定义件 §五.2 遗留口）＝**同一问题域、不同来源法度的技法卡**（例：同一冲突处理议题下的两家方法），decoy 集从注册库内按问题域标签选取 | §三 B-3；FM-M-01/03；C9 |

### 1.2 生成段与判分段分离（退出码可复现的实现口径）

S3 验收行「source-anchor 退出码可复现」＝确定性判据口径。生成段（跑模型答题、三臂作答、×5 重蒸）＝非确定，产物落盘＋哈希；判分段（validator 本体）＝只对落盘工件做确定性判定。**validator 退出码闭集与断言工具同款三值**：0＝全层绿；1＝任层 fail；2＝工具自身错误（fail-closed 不得吞成 0）。同输入（同工件集＋同预注册件）连跑退出码与逐项读数全等。

### 1.3 哈希泄漏比对规程（照前置定义两轴衔接表）

- 输入＝两轴切分预注册件（T 读数：时戳＋语料库哈希；题库指纹）＋评估工件。
- 归一化：NFKC＋去空白＋全半角折叠＋casefold。
- 比对两式：①相等式——sha256(归一化题面) ∈ {sha256(语料段落/分块)}；②包含式——归一化题面（长度 ≥20 字符）作子串出现在归一化语料全文。任一命中→`leakage_check`＝`已检-在语料内`→该测试集作废重建（FM 处置）；全不命中→`已检-不在语料内`。
- 防改题校验：题集重算哈希 ≠ 预注册题库指纹＝「题库被改」直接 fail（预注册冻结纪律同族）。
- 时间切分可核对行：产物报告必含一行「时间切分测试集日期 > 语料截止日」＋T 读数（时戳＋语料哈希）与预注册件对账一致；validator 做日期差值＋哈希全等两检。

### 1.4 gate_source 双向断言（GS-1..3）的执行位

GS-1/2/3 留在 assert-tool（既有 20 项编号闭集不动，S3 批转实装）。实装基面＝验证记录目录（见 §三.4 落盘规格）：validator 每层判定写出一条验证记录（机读 json，字段＝validator-catalog 注册表），assert-tool 的 gs_* 函数读该目录做白名单双向 diff，**不匹配数＝0** 才绿。person 白名单需扩一值（见 §二.3），与 method 白名单互斥集合同步维护于 assert-tool 注册位。

### 1.5 与 assert-tool 的关系裁定：新脚本，不复用为扩展

**决定＝新建两 validator 脚本＋一个非判据共用件；GS 断言留 assert-tool；validator 不 import assert-tool 的判据函数。** 理由四条：

1. **确定性域不同**：assert-tool 头部钉死「无随机种子、无时钟」；source-anchor 消费留出集（固定种子对象）与预注册日期读数，public-anchor 消费盲评工件时间线——并入必破坏断言工具既有确定性契约。
2. **基面不同**：assert-tool 固定基面＝contracts/＋rejected/＋adapters/（声明面）；validator 基面＝产物实例＋评估工件＋验证记录（实例面）。混基面会让「契约面自检」与「产物评估」互相污染（FC-2 双向 diff 语义会被实例字段搅浑）。
3. **闸分离的物理体现**：B3 双向断言的工程形态＝两 validator 各自独立脚本、各自独立词表，grep 可查；共用一个入口脚本＝「门禁统一到最弱」的温床（四条坏信号③的构造位）。
4. **复用点正确形态**：validator 需要复用 BW-1/BW-2 词表与 ST-3 节闭集等既有声明面断言时，复用方式＝**读同一注册基面（contracts/＋adapters/）重实现薄封装**，词表本体单源在 assert-tool 注册位——validator 从 assert-tool 以纯数据常量 import（词表/闭集常量，不含判据函数）为允许复用形态；此 import 方向（validator→断言工具取词表）不构成判据互套，GS 断言仍以验证记录 gate_source 字段为准。

### 1.6 run-to-run ×5 方差协议（D6）

- 对象＝当批进入 S3 评估的产物对象；同一冻结语料重蒸 ×5（生成段跑五次）。
- 一致性读数两行：①断言通过向量一致率（5 次 L1 断言结果向量的逐位一致率）；②要素锚点复现率（5 次产物 source_id 锚点集两两 Jaccard 均值）。
- 报告行入产物报告：「run-to-run ×5：断言一致率 n/5；锚点复现率均值 x（统计口径＋样本量＋一致性系数三件套随附，BW-3 适用）」。缺该读数行＝S3 验收该行不过（§四崩塌点④处置）。

### 1.7 跨族裁判＋位置对调（D8，harness 共用规程）

盲辨/盲评题组由 ≥2 个不同模型家族裁判各自独立判定；同裁判对同题组做位置对调双跑取平均（治 self-preference＋position bias）；读数按家分列，跨家分歧原样留档（FM-S-04 处置，不平滑）。盲标操作规程见 §三.2。

## 二、public-anchor validator（person 轨软门）规格

### 2.1 层结构

| 层 | 层名（gate_source 取值） | 内容 | 当期门禁资格 |
|---|---|---|---|
| L0 | `格式检查表` | D2 嫁接机械位：结构（五层节闭集 diff＝∅〔ST-3 perspective 侧〕）、禁用词（BW-1 角色扮演禁语＋BW-2 无据断言词）、格式（test-prompts 回归件在场可解析〔ST-4〕、要素三态标注成对〔FC-3〕）——先判后盲评，L0 fail 不进盲评层 | **当期唯一门禁位**（S0b 元组未交付态下，放行仅依机械断言，R7/R24/§四①处置口径） |

### 2.2 盲评 rubric 结构

- 维度闭集四维：`声音保真`（表达 DNA 层再现而非语录复读〔FM-P-03 对应面〕）／`框架运用`（用其框架分析问题而非转述其结论，C14 定位）／`弃权表现`（无据问题落限定/弃权档位，D9）／`反角色扮演`（无「以他的名义」类滑移，C14/BW-1 对应面）。
- 量表：每维锚定五级（1–5）；rubric 锚定语 per 维随 validator-catalog 附录落盘（评分锚点文本预注册，中途变更走独立提案）。
- 盲评操作：答题/评分双 agent 分离＋元信息隔离（C16 保留部分）；裁判只见题干＋两匿名候选输出，不见轨别/产物 id/版本。
- **无一致率数据条款（入规格正文）**：本 validator 在 S0b 交付元组到位前，全部 judge 层读数（L1/L2/L3 分数与辨认正确率）只作参考位、不得作门禁位；validator 报表上 judge 层读数行强制并列打印 `calibration_state` 当前值（缺省即「待校准」，fail-closed）。

### 2.3 person gate_source 白名单扩值（随交付面重交付）

既有 PERSON_GATE_WHITELIST＝（盲评rubric, 绝对线, decoy, 泄漏检查, 人工锚点卡）无「格式检查表」值；D2 嫁接机械层若不注册则 GS-1 无词可记、若记「机械断言」则被 GS-1 误咬（互套假阳性）。**本件裁定＝扩值为六值：（盲评rubric, 绝对线, decoy, 泄漏检查, 人工锚点卡, 格式检查表）**；扩值属门禁面重交付程序（AC-5 扩词程序同族），随 S3 批交付（assert-tool 词表＋断言目录 GS-1 文案随动）。命名取「格式检查表」以对齐 C4 处置句（评分卡格式检查表化），与 method 白名单「机械断言」刻意异名——异名即 B3 不互套的词表体现。

### 2.4 嫁接件②（D2）与两轴衔接表照接

60/40 固定种子留出集（person 侧，D2）：种子预注册、hold-out 名单不落可检索件、validation 选版前隐藏——逐条照前置定义 §2.4 末行接口。D3 嫁接进 source-anchor 见 §1.1 L5/L6。P 配平读数消费位见 §1.1 L6 与 §三.2。

## 三、harness 归口（A7／R21 五要素）

### 3.1 单 owner 声明落点

「harness 执行单 owner」声明落**交付面** `gates/validator-catalog.md` 顶部性质声明节（声明文本：「harness 执行单 owner＝当批 validator 票的执行席；起草席/审计席/QA 席不并跑 harness，只读验证记录」）。落交付面理由＝该纪律是产线常设纪律非一次性安排，须随产品线生命周期存续；过程案卷会过期，交付面不会。

### 3.2 D12 独立判据行＋近邻对照＋二选一＋裁判盲标操作规程

- **D 表独立判据行三字段已入 D12（v2.1 P-1 态），本件照抄不再定义**：判据文本＝近邻人物盲辨二选一正确率；验收位＝S3 harness 独立报告行；排期＝S3。validator 报表中该行以独立行存在，**无 harness 总分聚合概念**——「不得以 A7 总通过推定」的机械体现＝报表无总分字段、每行独立读数独立判定，GS/BW-3 咬任何聚合表述。
- **近邻对象对照**：person 轨 N(O) 取前置定义件 J-11 关系标记名单；method 轨近邻定义由本件补死＝同问题域不同法度卡（§1.1 L3）。近邻语料不并入 O 语料库（前置定义 §2.2 照引）。
- **二选一题组构造**：题干构造规则取自预注册件（不含答案位置）；候选成对呈现（真产物 vs 近邻产物），标签匿名化（A/B 随机化由生成段完成，判分段只读落盘对位表）。
- **裁判盲标规程**：裁判不见轨别/对象名/版本/对方裁判读数；位置对调双跑（同裁判两跑 A/B 位互换，取平均）；跨 ≥2 模型家族各自独立跑；家族读数分列，跨家分歧原样留档转人工闸（FM-S-04）。
- **与 D12 排他性正确率独立报告行衔接**：盲标规程产出的辨认正确率即 D12 读数源；该行只进报告行，不并入任何 validator 层的 fail/pass 判定（source-anchor 的诱饵层与 D12 行分离：诱饵层＝触发层机检，D12＝人物/法度归属辨认层）。

### 3.3 验证记录 schema（R25 同源定义面）

`gates/validator-catalog.md` 内机读注册表＝验证记录字段与 harness 字段的**唯一同源定义面**（R25/§七 B7/§10.3）。字段注册（初版闭集，validator 实例字段 ⊆ 注册表，FC-2 同款双向 diff 纪律适用到 validator 层）：


- 「判定」三值含 `未验`：规程在场但数据/环境不可得的行一律记 `未验`，不算 PASS 不算 FAIL（PENDING_STAGE 同族口径），汇总单列。
- assert-tool GS-1..3 实装基面＝验证记录目录内全部记录的 `所属轨`×`gate_source` 白名单 diff；validator 写记录时也自检一次（双保险，两处同一注册表）。

### 3.4 对照组构成表落盘位置：过程域证据面

**决定＝`.collab\evidence\harness\`（过程域证据子域），不落后交付面、不落 `.collab\board\`。** 理由三条：

1. 交付面＝可复用工具与规范面（工具/词表/契约/注册表）；对照组构成表是**按对象按批次**的评估证据数据，落交付面会把实例数据混进契约基面，污染 FC-2 类声明面机检。
2. `.collab\board\`＝AC-5 三栏结构记录面，栏名闭集（本轮改动/触发的坏信号/人工闸结论），评估数据塞入必违看板契约；看板是治理记录件非数据仓。
3. `.collab\evidence\` 已有 gates/、blind-eval/ 证据子域惯例，验证记录（R25 可回查位置）与对照组构成表同域存放＝回查一处到位。**交付面只注册路径**：validator-catalog 顶部登记「验证记录与对照组构成表落盘路径＝`.collab\evidence\harness\`」——注册在场＝交付面，数据本体＝过程面。
- 对照组构成表内容闭集：臂名×{宿主、模型标识（见 §四.2 限制）、工具面、预算上限、题集指纹、臂产物哈希}；缺行＝对应三臂对照行记未验。

## 四、平台依赖两确认处置案（不假装绿）

### 4.1 确认①：装载记录可导出（R20·S3 验收前置项）

**当期结论＝实证不可得。** 盘上可得证据（本稿实测采样）：宿主环境存在**注册面**（用户技能目录列表＝注册/启用态可读），但未见**装载记录导出接口**的盘上证据——会话元数据文件字段面（conversationId/resumedAt/startedAt/userId/workDir 级）无技能/装载字段；审计日志采样日（当周段）事件类别以命令安全类为主，未见技能装载类事件；未做穷尽全盘检索（穷尽与否本身不可证），故按保守口径记「实证不可得」。

**后果口径（写死）**：R20 判据「注册分卷哈希与实际装载一致」依赖装载记录，判据悬空 → **S3 该前置项记「未验」不记绿**；连带 token 收益反证判据只实装一半：「分卷 token 量 vs 全量装载 token 量」比对＝对注册分卷文件本地可测（当期可实装）；「实际装载 token 量」侧不可得 → 该读数行记未验。

**接口预留规格**：validator-catalog 注册装载记录导出 stub schema（字段：session_id／分卷id／分卷哈希／装载时戳／装载token读数；类型占位记法同 EG-5），并在验证记录字段注册表中预留 `装载核对` 字段位（当期恒 `未验`）；平台侧未来提供导出能力时，validator 接桩即可实装，不动既有 20 项与词表闭集。

**风险登记（入 S3 票面）**：R20 判据悬空是**验收缺口**非实现缺陷；S3 票不得以「stub 已建」推定该判据绿；缺口持续挂看板悬置升级线（连续 3 板次无迁移强制列人工闸议题，AC-5 悬置升级阈值）。

### 4.2 确认②：三臂宿主环境可复现

**当期结论＝部分可实装。** 分项判定：

| 三臂前置条件 | 当期实装程度 | 依据/限制 |
|---|---|---|
| without_skill 臂 | 可实装（不注册产物即无臂会话） | 宿主显式注册制下天然可得 |
| new 臂 | 可实装（注册当版产物） | 同上 |
| old 臂 | 可实装（旧版以独立 kebab 名注册并存） | 注册制允许同名系不同 id 并存；版本谱系哈希入构成表 |
| 同宿主 | 可实装 | 同一 WorkBuddy 宿主会话族 |
| 同工具面/同预算 | 可实装（票面控制题面与提示约束） | 构成表登记工具面清单＋预算上限行 |
| 同模型 | **规程在场、实证受限** | 宿主会话元数据不含模型标识字段（§四.1 同基面实测）→ 模型一致性读数＝会话侧声明值，盘上不可独立校验；构成表设「模型标识（声明值）」行＋该行标记不可独立校验；由此任何以「同模型」为前提的增量读数附局限声明 |
| 匿名标签 | 可实装 | 生成段落表，判分段读对位表（§3.2） |

**口径**：三臂对照层当期可按上表实装并出读数，但「同模型」一致性属「规程在场待实证」态——S3 验收映射（§五）该子行记第二态，产物报告三臂行须随附模型标识声明行＋局限声明。跨 ≥2 模型家族裁判（D8）当期可行：宿主内多家族会话＋文件交换路径已有既有机制惯例（盲评证据子域在场）。
