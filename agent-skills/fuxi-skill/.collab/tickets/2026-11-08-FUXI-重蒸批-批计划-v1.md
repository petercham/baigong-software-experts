## 二、重合对象处置口径（david-finch／miyazaki-perspective／mrbeast-perspective）

1. **对象同一性判定基准**＝对象所指真实人物，非外部目录名拼写：david-finch＝David Fincher＝本仓 active 条目 david-fincher-perspective（FX-U6 入池链）；miyazaki-perspective＝宫崎骏＝miyazaki-hayao-perspective（FX-U16 入池链）；mrbeast-perspective＝MrBeast＝本仓同名 active 条目（FX-U11 入池链）。历史产物目录名差异（finch/fincher、miyazaki/miyazaki-hayao）不构成第二对象。
2. **重蒸目标＝验证工序，非重复入池**。三对象逐对象六步链全走（登记→分类→蒸馏→验证闸→去向→装载注记），产物去向＝`products/archive/<对象目录名>-rb<N>-对照/`（archive＝历史记录区·过程留痕·免产物级机检·装载不被触及），**不落 pending、不入 active**；随附对照报告（新产物 vs 在册 active 产物：节闭集 diff／条目数口径／诚实边界厚度／验证闸三态对照读数）落该票回执或 `.collab/qa/`。
3. **入池冲突规则（写死）**：active 生效池同一对象 id 单条目——同对象第二条目禁入池（FC-6 枚举面与装载面单源前提）；若对照蒸产出质量优于在册产物，替换＝独立提案＋版本审计另票（AC 入池规程），本大批零替换动作。
4. **对照面≠语料面**：外部历史产物正文只作对照读数基准（旧工序输出形态），禁入语料落盘面、禁计入 EG-6 分母——细则见票面「语料口径裁决」节（自我循环禁令）。
