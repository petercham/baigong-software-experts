## 节闭集表

- 能力卡六段节闭集＝`R 原文／I 诠释／A1 案例／A2 触发场景／E 执行步骤／B 边界`；段名注册闭集＝断言工具 `TECHNIQUE_CARD_SECTIONS`＝(R, I, A1, A2, E, B)；段描述名注册闭集＝断言工具 `TECHNIQUE_SEGMENT_DESCS`（与 `adapters/method.md`「technique-IR RIA++ 六段」节正文逐字全等）。
- **段名前缀归一化口径（钉死防假咬）**：产物节头书写形态＝`<单字母段名> <段描述名>`（如「R 原文」）；机检 diff 基面＝节头段名前缀 token 提取后与注册闭集 diff；描述名部分不参与段名 diff，但须与注册描述名逐字全等（改名＝咬）。裸段名形态（「R」）与全形态（「R 原文」）两写法同判合法。
- 卡体五字段闭集＝`出处／触发／步骤／边界／验证状态`（注册位 `TECHNIQUE_CARD_FIELDS` 逐字全等）。
- B 段存在且非空占位＝BW-4（B-7 铁律机械位）；R 段必为原文引文并带 `source_id`＋位置成对（FC-3）。
- 产物实例节结构 diff＝∅ 的机检＝ST-3（产物实例注册目录全量扫描；无实例＝空扫描合法态判绿，判据活性由 selftest 咬放配对实证：归一化放例／改名咬例）。
