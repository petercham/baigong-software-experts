# fuxi-skill · method adapter（technique 轨填料件）

> 性质＝交付件本体（自包含成文）。节闭集＝恰六节（多节／缺节／改名＝diff 非空即 fail），节名与骨架闭集逐字全等。
> 记法：R<n>＝决策清单条款；D<n>＝设计稿 v2 评估机制行；B-<n>＝设计稿 v2 分轨项编号；B<n>＝设计稿 v2 界线总表编号；C<n>＝设计稿 v2 保留清单行；EG/FM/AC-<n>＝同包 `contracts/` 契约节号；ST/FC/BW/GS-<n>＝同包 `gates/assertion-catalog.md` 断言编号；J-<n>＝同包 `adapters/classifier.md` 判例编号。
> 轨界纪律：本件＝technique 轨 adapter 填料（B1），不得含 persona 轨 IR 节名——机械断言＝ST-7（persona 轨 IR 节名字样命中数＝0）；两 IR 永不相并（B2）。

## Adler 分析阅读＋五路提取

- 方法论照搬入本 adapter（C2）：先做分析阅读（结构／解释／批判／应用四阶），产出 BOOK_OVERVIEW（全书结构总览：主问题／结构骨架／主张清单／作者试图解决的次问题），再入五路并行提取。
- 五路＝定义term路／关键句路／论证链路／实例路／边界条件路，五路各自落盘，提取动作只作用于收讫语料（见「Air-gapped 纪律」节）。
- 提取判据（本轨专用）：跨段落佐证（≥2 独立段落）＋可执行性＋任务效用；「只被完整解释一次也可入选」为合法态（B-5）——与 person 轨跨领域复现判据字段语义不同，不共字段。
- 跨段落佐证每处带可回查位置（`source_id`＋位置双形态成对，FC-3）；教科书／操作规程类封闭文本（J-5 案型）照常走本节流程，语料封闭给定。
- 术语壁垒护栏：I 段诠释须以读者可执行的语言重写原文术语（FM-M-02 挂接：I 段判项 fail → 降级重写）。

## technique-IR RIA++ 六段

- 能力卡六段节名闭集（与 `gates/assertion-catalog.md` ST-3 technique 六段注册闭集逐字全等）：R 原文／I 诠释／A1 案例／A2 触发场景／E 执行步骤／B 边界。多一节／缺一节／改名＝diff 非空即 fail（ST-3）。
- 卡体五字段闭集（同注册位逐字全等）：出处／触发／步骤／边界／验证状态。
- B 段（边界）存在且非空占位＝机械断言 BW-4；缺 B 段或空占位＝「边界必须明确、验证不过不晋级」铁律机械位缺位，不晋级（B-7 铁律）。
- R 段必须为原文引文并带 `source_id`＋位置（FC-3）；A2 触发场景段承载触发断言的语义面（与 M-3 护栏衔接）。
- `验证状态` 字段取值与 AC-2 状态字段闭集同源；未过验证记 `未验`，不得进取门禁位（AC-3）。

## 防误触发护栏

- 三护栏对象＝触发不准／术语壁垒／跨技能混淆，逐条挂接 FM-M-01／FM-M-02／FM-M-03（处置按 failure-modes 分流三态：降级／阻断／转人工闸，无逃逸路径）。
- 护栏机制＝B 段边界＋诱饵测试＋触发断言（B-3）：每张卡的 A2 触发场景须能被 decoy 题组证伪——「不该触发的题面触发命中＞0」＝FM-M-01 咬合读数（诱饵命中读数口径归 S3 harness）。
- 跨技能混淆＝decoy fail：与邻近技能卡触发域重叠无法区分时阻断晋级（FM-M-03）。
- 触发断言属 method 轨硬门类判据（机械断言→三臂对照→诱饵测试→留出集，GS-2 白名单）；本轨验证记录不得调用 person 轨软判据（GS-1/GS-2 双向 gate_source 断言，不匹配数＝0 为 S3 硬验收）。

## 即用即走语义

- 装载语义＝即用即走：触发命中即读卡，用完退场，不常驻对话全程（B-4）；本轨失效模式＝误触发（M-3 护栏的失效对应面），误触发检出属 S3 评估面。
- 装载分卷按 R20 口径照引不展开：产物分卷在注册期预编译；装载期仅可从已注册分卷中选择；判据＝注册分卷哈希与实际装载一致；另设 token 收益反证判据（装载后 token 量对比全量装载，可机械验证）。
- 与 person 轨常驻语义分开，不做强行统一路由（B8）。

## Air-gapped 纪律

- 外部请求计数恒 0（R19／B11）：本轨全部条款不含任何联网工具调用；本节为静态检查对象——本文件联网工具调用条款命中数＝0，且声明行（本行）在场＝S2 验收读数（声明在场＋静态读数）。
- 语料封闭给定：原文由用户提供（封闭语料），「不要在没有文本的情况下凭记忆蒸馏——宁可停下来问用户要」（B-6）；无文本即停＝向用户索取文本，走 FM-S-01（转人工闸：索取补充语料），不得凭基座记忆补全。
- 凭记忆蒸馏＝把基座先验冒充蒸馏产物的泄漏面：hold-out 时间轴 T＝给定文本收讫时点（封闭语料一次性收讫记时戳；分批收讫以「评估语料包封存」封存时戳为准，预注册件登记）；测试题/锚点题题面与语料库规范化哈希泄漏比对，命中＝`leakage_check`＝已检-在语料内 → 该测试集作废重建（method 侧泄漏处置）。
- 编译形态衔接：本轨编译 single／pack／bundle 三形态（B10／R23）；bundle 内 technique 层与 persona 层各自持本轨验证状态字段、命名空间隔离、不得互借分数（FC-5 机械检出，两 adapter 互斥字段检查＝ST-6／ST-7）。

## 语料主题配平

- D10 施工项（本 adapter 语料执行面）：对本轨语料做主题配平检查——主动补齐配平样本，或做减除式蒸馏留痕；二者其一留痕在场＝「配平检查通过」读数可核对（S2 验收读数位）。
- 本轨配平特防＝「卡片长出主题偏好而非风格」（content leakage 教训）：能力卡的 A2 触发场景分布不得全落在语料头部主题。
- 检出口径：「题面主题 ⊆ 语料头部主题集且无配平留痕」→ 记未验（hold-out 配平轴；缺两轴切分预注册件＝该对象评估记未验，fail-closed）。
- 近邻对象（同框架异家法等近邻技法文本）语料不并入本对象语料库（防近邻互蒸）；近邻关系标记随注册登记（J-11 案型）；配平轴读数与时间轴读数并列独立报（R21②同族）。
