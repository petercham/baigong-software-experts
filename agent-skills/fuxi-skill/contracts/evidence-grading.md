# fuxi-skill · 证据分级契约（evidence-grading）

> 性质＝交付件本体（自包含成文·双纪律＝节闭集〔恰六节，多节/缺节/改名＝diff 非空即 fail〕＋字段名闭集〔本文件声明字段名与断言工具注册位双向 diff＝∅，未注册字段零容忍〕）。
> 记法：EG-<n>＝本文件节号；ST/FC/BW/GS-<n>＝断言目录编号（`gates/assertion-catalog.md`）。本文件与同域断言工具按注册路径静态对账（FC-2），正文零过程域指针。

## EG-1 适用范围

- 适用对象＝双轨（person／method）全部候选单元与产物要素级标注。
- 不含采集姿态——采集姿态口径属各轨 adapter，不入共享内核。

## EG-2 三级标注

字段名＝`证据等级`；取值闭集＝`原文可证实`／`跨文本推断`／`模型补全`。

- 硬规则：`模型补全` 强制显式标注，不得以未标注隐式存在。
- 允许且鼓励在证据不足处直接写「证据不足」不补全（与拒答机制措辞纪律衔接，见 `artifact-contract.md` AC-4）。
- **轴区分**：`证据等级` 标注「该要素内容与来源的关系」（可证实/推断/补全）；`evidence_grade` 标注「该结论的证据获取方式」（人工验证/机械断言/LLM 判定，注册位＝AC-2）。两轴正交、各自闭集、不得互推互替；两字段名在 FC-2 注册表各自独立注册，防字段语义并轨。

## EG-3 来源三态

字段名＝`来源态`；取值闭集＝`本人原文`／`第三方转述`／`模型推断`（三态均可回查）。

- 正交声明：来源态与三级标注正交——`本人原文` 也可以是 `跨文本推断` 的原料，两字段各自独立取值，不得互推。
- 模型推断态哨兵：`来源态`=`模型推断` 且要素无外部来源时，`source_id` 允许固定哨兵值 `model-knowledge`、`位置` 允许固定哨兵短语「模型内部既有知识，无外部回查位置」；哨兵形态形式满足 FC-3 成对判据，同时如实表达无外部回查语义——哨兵只对本条所列 `模型推断` 态开放，不豁免其余来源态的回查位置义务。

## EG-4 三问可答口径

任一候选单元（在选候选期与淘汰留档期皆算）必须可机械回答三问：

1. **证据等级**？→ 双轴字段 `证据等级`（EG-2 闭集）＋`evidence_grade`（AC-2 闭集）同时在场；
2. **对照臂有无**？→ 字段 `control_arm`（AC-3 闭集）；
3. **测试题是否在语料内**？→ 字段 `leakage_check`（AC-3 闭集）。

三字段缺任一个＝该单元不可答，ST-5「三问」判据与「候选单元可答三问」验收不过。

## EG-5 候选单元记录

记录形态＝机读块（markdown 内嵌 fenced json 块，保证可解析）。本节字段名注册表（机读块＝FC-2 双向 diff 的声明面基面，工具读本块与注册表对账）：本节机读块适用域＝候选筛选期与淘汰留档期的候选单元记录；产物要素级标注的落盘形态＝产物本体正文内联记法（反引号字段名 `字段=值` 同行并列），其成对纪律机检＝FC-3 产物要素行级侧——不要求产物另附要素机读块。

字段定义（字段名闭集≡上列字段注册表；「string」／「number」＝类型占位记法，非状态取值）：

| 字段名 | 取值/类型 | 说明 |
|---|---|---|
| `candidate_id` | string | 候选单元编号，批次内唯一 |
| `所属轨` | `person`／`method`／`bundle` | 轨别标记，沿用 ST-4 `所属轨` 取值风格 |
| `证据等级` | EG-2 闭集 | 三级标注（内容-来源关系轴） |
| `来源态` | EG-3 闭集 | 三态标注（可回查） |
| `evidence_grade` | {人工验证, 机械断言, LLM 判定} | FC-1 注册值，逐字同集（证据获取方式轴） |
| `calibration_state` | {校准态, 待校准} | FC-1 注册值，逐字同集；缺省即「待校准」（fail-closed） |
| `source_id` | string | 与 `位置` 成对（FC-3） |
| `位置` | string | 章节/页码类位置形态（FC-3） |
| `control_arm` | {三臂, 无臂, 未测} | 三问之二（AC-3 证据卡对照臂栏） |
| `leakage_check` | {已检-不在语料内, 已检-在语料内, 未检} | 三问之三（AC-3 泄漏检查栏） |
| `abstain_tier` | {有支持, 有限定, 无支持但貌似合理, 明确幻觉} | 仅结论级条目必填；与 BW-2 注册四档逐字同集 |

## EG-6 语料门槛登记

可机检门槛数值登记位（门槛参数≠领域判据）：

- `一手占比门槛`＝70（一手占比须越过此门槛，单位＝百分比）；
- `贴线带脱离线`＝80（贴线带口径〔裁定源＝皮总 EG-6 合格口径提升裁定（2026-11 裁定誊录在册）〕：`一手占比` 读数≥`一手占比门槛` 但＜`贴线带脱离线`＝仍在贴线带——仍在贴线带者触发补充调研（扩大搜索范围，执行通道＝本节补批封印链工序）；`一手占比` 读数≥`贴线带脱离线`＝脱离贴线带；门槛不过者处置照 FM-S-01 现行受限路径不变——本条只增「达标未脱线亦触发补研」一档，不改受限路径语义）；
- `一手条目数门槛`＝5（薄面判定标准〔裁定源＝皮总薄面判定明确化裁定（2026-11 裁定誊录在册）〕：`一手条目数`＝样本内 `来源态`＝`本人原文` 态要素条目数（与 `一手占比` 分子同式直取；纯度轴与绝对量轴两维分立——先例＝本节参考评分口径与门槛两分分立口径）；`一手条目数` 低于此门槛＝「薄面」；薄面与占比读数不达线为两维独立触发依据——任一触发即触发补充调研，不因另一维达标互抵）；
- `补充调研重触发上限`＝3（补充调研自动重触发三限条款〔裁定源＝皮总补研自动重触发三限裁定（2026-11 裁定誊录在册）〕：由贴线带或薄面触发的补充调研＝自动重触发执行（转人工闸出裁索取分支存续不变），每对象自动重触发次数上限＝3；`补充调研重触发计数`＝该对象经封印登记落账生效的补充调研批次累计数，登记落点＝产物条目 registration.md `语料门槛登记（EG-6）` 节内随册计数读数行（封印登记落账一次计数加一·append-only 照现行登记纪律）；计数达上限而 `一手占比` 仍不过门槛、或仍处贴线带／薄面＝停止自动重触发——去向登记形态＝「暂缓入池」（registration 去向行照登＋人类报告等待裁定：报告件落点＝过程域 receipts 子域候裁报告件·落盘纪律承本节封印登记件；衔接 FM-S-01 转人工闸出口——暂缓入池非出清，禁自动出清禁自动入池）；计数未达上限而重跑读数达门槛且脱离贴线带与薄面＝照现行受限行随撤条件口径处理）；
- `新鲜度窗口月数`＝12（参考评分窗口口径〔裁定源＝皮总新鲜度降参考评分裁定（2026-11 裁定誊录在册）〕：语料条目落最近此月数窗口内者占要素条目总数之比值＝该对象之新鲜度参考评分，登记形态照现行「落窗口内条目数/要素条目总数」比值式，读数照登照产、供人类决策参考；新鲜度非门槛——读数不构成入池资格、不作门禁判据、不触发 FM-S-01、不产生受限行；蒸馏对象不必在世或持续有新信息，历史人物类对象不因新鲜度成受限项）；
- 语料黑名单：登记必须在场且非空（在场性判据，不设状态字段）。

- 补批采纳面条款（补充语料批次入样闭集）〔裁定源＝皮总甲案裁定（2026-11 裁定誊录在册）〕：补充语料批次一经采纳，其全部条目一律入样本分母——不分 `来源态`／`证据等级` 取值（含第三方转述态、含跨文本推断级），分母＝该对象已采纳样本的全部要素条目数（与登记行统计口径「要素条目总数」同式）；不得按占比读数后果选择性采纳——采纳与否之判据不得以「入样后读数是否越线」为据，读数越线的唯一合法路径＝增加合格一手条目。
- 「采纳」定义动作＝哈希封印登记落点：补批批次之采纳＝该批次逐文件哈希封印登记件落账（体例三段＝逐文件哈希表＋独立复验命令＋未归位对象指针，先例见 FX-U3 语料批次哈希封印登记件〔t9 首批十八文件封立面〕与 FX-U8 同制件；登记件落点＝过程域 receipts 子域＝史实锚制入库面，因语料落盘面在排除面内、逐文件哈希必落入库登记件方可对账）；封印登记落账之前该批次＝未采纳态，其目录不入样本集、不入 `一手占比` 与新鲜度两类读数分母。
- 补批落盘与命名语义：补批目录＝批次目录内与首批对象目录并列之对象目录，名＝对象名＋批次后缀 `-suppl`；归位纪律适用面照语料归位既有口径＝复制归位＋逐文件哈希对拍，禁以移动替代复制（源侧原件保留）。
- 补批封印链工序（FM-S-01「索取补充语料」分支终点·五步闭集）：转人工闸出裁索取补充语料 → 取证落盘补批目录（未封印＝取证态不入算）→ 归位与逐文件哈希对拍 → 哈希封印登记件落账＝采纳动作生效点 → 样本集并入（全件入样）→ 登记读数修订触发链（封印登记落账后经修订票改登本节点名的两读数行，原地改登或第二版登记件两形态之一随修订票定形并声明受限行随撤与否）→ 重跑 `一手占比` 与新鲜度窗口读数再呈转人工闸。
- 违规形态口径：已采纳条目之剔除或改登必经登记注记路径（封印登记件或登记行内留痕注记，附剔除理由与经裁出处），禁无痕删样——无任何登记注记的样本集缩水即违例，无论读数是否因此改善。
