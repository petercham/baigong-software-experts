## 二、施工规格

### S1 · 预注册与语料冻结登记（commit-A 第一笔）

登记件 md 含机读 json 块，形态（字段闭集钉死）：

```json
{"批次": "s0c-anchors-b1",
 "对象": [{"对象id": "…", "所属轨": "person|method",
           "语料冻结时戳": "ISO8601",
           "语料库哈希": "sha256(批次目录 corpus-<对象id>-*.md 按文件名序，逐文件 harness-common.normalize_text 归一后以换行拼接，sha256_hex)",
           "来源描述": "联网公开语料|用户提供已落盘语料"}],
 "起步值": {"每对象每轨": 8, "题数下限": 5, "对象数": 2, "加题上限": 30, "预算上限": 128,
            "bootstrap迭代": 5000, "种子": 20261031, "达标线": 0.6},
 "规范哈希": {"soft": "sha256(normalize_text(标注规范-soft全文))", "hard": "…同法…"}}
```

起步值九参数＝validator-catalog §四 S0b 预注册表逐字照誊（一经注册不得变更，R1）。批次目录放逐字节副本 `prereg-s0c.json`（验收做 diff）。

### S2 · 题库构造（两轨各 16 题＝2 对象 × 每对象 8 题）

每题字段闭集（json 顶层＝list）：

```json
{"题目id": "<对象id缩写>-s01…", "题面": "…", "对象id": "…", "所属轨": "person|method",
 "锚料日期": "ISO8601", "来源描述": "…"}
```

- 时序检（R13）：每题 `锚料日期` ＞ 该对象 `语料冻结时戳`（person）/`收讫时戳`（method，登记件内以冻结时戳承载）——构造完成后 python 逐题比对读数入回执，违例题只换题不挪基准。
- 软门题＝对锚点对象的边缘判断题（期望产出档位可判），档位词表＝`abstain_tier` 四档（有支持／有限定／无支持但貌似合理／明确幻觉，validator 侧既有闭集）；硬门题＝对法度文本断言的判定题（期望判定 ∈ {PASS, FAIL}，validator-catalog 判定词表既有值）。
- 两题库对象集互不相交、题面不得互见（R12 两套独立的第一道闸）；题库不得含「预设答案」字段（盲标独立性）。

### S3 · 两标注规范（独立成文，R12）

`标注规范-soft.md`／`标注规范-hard.md` 各自成文：判定任务定义＋档位/判定词表＋标注纪律（不见对方标注、不见题库外线索、独立完成后才合并）＋「规范哈希变更＝作废重标唯一触发」声明行。规范哈希（S1 登记件两字段）＝对各规范全文跑 `harness-common.normalize_text`＋`sha256_hex` 实测值，登记与落盘工件两处一致。

### S4 · 盲标执行（标注者＝主理人＋起草席，小组档）

工件形态（照 s0b-kappa 输入面 schema，自包含成文）：

```json
{"规范哈希": "<S1 登记值>",
 "标注单元": {"标注者甲": {"<题目id>": "<档位或判定>", "…": "…"},
              "标注者乙": {"<题目id>": "…", "…": "…"}},
 "加题数": 0, "标注读数数": 16, "补题记录": [], "标注完成时戳": "ISO8601"}
```

- 标注者甲＝主理人、标注者乙＝起草席（两规范各自适用：soft 工件填四档词表值、hard 工件填 PASS/FAIL）。
- 独立性程序：两标注者各持题库副本独立完成标注单元，先完成者工件段不得在另一份完成前共享；完成后合并写入同一工件文件（一次成文）。
- 每轨 `标注读数数` ＝16（8 题 × 2 标注者；两轨合计 32 ≤ 预算 128）；`规范哈希` ＝登记值逐字（不一致＝工具侧作废重标触发，禁手工对齐）。
- `gold-assertions.json`（硬门金标对）**本批不出**：断言结果需 method 产物实跑面，S0 验收段无产物级断言可金标化（R10 时序口径「S0b 段不含产物实测」）——工件缺位＝工具判据行②记未验（fail-closed 合法当期态，如实不补合成）。
