# 分票对象审计（票卡/批次）

> 出处：K1–K6＝本地约定（票制归纳）；INVEST＝业界范式（Bill Wake）；「验收判据含本体面尺」＝本项目治理教训收敛（本地约定）。

## K1 票卡三行（缺一即不合格）

| 行 | 判法 |
|---|---|
| 范围 | 一张票只干一件事；范围可一句话读完；含明确「不做什么」 |
| 断言面 | 判据逐条列，可机检优先；每条能判真假 |
| 预估改动面 | 预计触及的文件/模块/字节量级（用于事后对账「改动是否越界」） |

## K2 INVEST

| 字母 | 含义 | 判法 |
|---|---|---|
| I | Independent | 不依赖未完成的其他票（有依赖须写明前置票） |
| N | Negotiable | 范围可谈、本质不可谈（本质＝什么算完成） |
| V | Valuable | 能说清做完后谁受益/什么变好（答不出＝伪票） |
| E | Estimable | 能估（估不出＝范围没定清） |
| S | Small | 一批可完成；超一批＝拆 |
| T | Testable | K1 断言面齐 |

## K3 判据面完整（防「票面全绿≠做完」）

| # | 测项 | 判法 |
|---|---|---|
| K3-1 | 本体面尺 | 判据必须包含「对象本身达没达标」的尺，不能只有治理面（计数/指针/体量/标题） |
| K3-2 | 判据来源 | 判据＝立票时所列；**执行方自加的判据单列「质量报告」，不计入绿** |
| K3-3 | 三态取值域 | 每条判据声明取值域：绿／未绿／不适用·已移出（注明移到哪步·谁拍） |
| K3-4 | 移出单列 | 「已移出」不得计入绿；计数式＝绿＋未绿＋移出＝总数 |

## K4 批次纪律

| # | 测项 | 判法 |
|---|---|---|
| K4-1 | 一票一批 | 批号＝票号；一批只推进一票（防「批下另开」治理循环） |
| K4-2 | 候办只减不增 | 候办池进一件须同批关一件；到期未关＝自动升阻塞或撤销（日落） |
| K4-3 | 锁死批数 | 总票数/总批数有上限，新增须关旧或撤销 |
| K4-4 | 净收敛 | 每批报产出与净变化（±字节/±条目），不只报「做了什么」 |

## K5 审计边界（验可测性不验内容）

- 审计只看：每条判据能不能判、负样本齐不齐。**不重述范围、不预写方案、不替立卡**。
- 结论三选一：可启（附验真意见）／退回重立卡（只说哪条不可算）／无票（未立卡即无票，规划≠进展）。

## K6 票的死亡条件

- 每票带「什么情况下撤销/并票」一句；无死亡条件的票会永久挂账。
- 连续多批零落地的票＝升阻塞待拍，不许静默养着。

## 判定要点

- K1-断言面缺、K3-1 本体面尺缺、K4-1 一票一批破 ＝ **阻断**（票会假绿或失控）。
- K2 任一字母不合格＝**关注**（必带重立卡动作）。
- K6 缺死亡条件＝**可延后**（带「下批复核」触发）。
