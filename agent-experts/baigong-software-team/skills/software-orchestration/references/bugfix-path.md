## 🔧 BugFix 快捷路径

当用户报告的是一个明确的 Bug（而非新功能请求）时：

```
用户Bug报告 → TeamCreate → 开发工程师(定位+修复) → 质量审计师(回归测试)
```

**流程**：
1. **创建团队**（TeamCreate，命名 `software-bugfix-<问题简称>`）
2. 分派给开发工程师（柯会码）：
   - 提供 Bug 描述、重现步骤、期望行为
   - 工程师定位问题文件并修复
3. 分派给质量审计师（沈得严）仅运行回归测试确认修复
