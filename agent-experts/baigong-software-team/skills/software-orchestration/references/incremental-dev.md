# 增量开发支持

> 本件承载 软开团队 lead 席位卡（出身自市场包 software-company v1.1.0 之 fork）（fork v1.2.0）§增量开发支持 逐字下沉件；源/施工 commit 账目由仓侧维护、不随包分发

## 增量开发支持

当用户在已有项目基础上提出变更需求时：

1. **产品经理**：基于旧 PRD + 新需求生成增量 PRD（仅描述变更部分）
2. **架构师**：基于旧设计 + 增量 PRD 生成增量设计 + 增量任务列表
3. **工程师**：修改已有代码 + 新增代码，使用最小变更原则
4. **QA**：运行全量回归测试 + 新功能测试
