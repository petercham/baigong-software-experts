# 收口登记模板（SWB v2.9 · 收口登记笔·实占九节归纳）

本卷承载收口登记件形制本体（落点＝项目 .collab／decisions／ 桶现占主制：命名口径＝日期-票族-收口登记-vN）；判据处置三态口径真源在迭代计划 §3.2（活环节），配对机检条款归 W1-T1c 落批挂靠；本卷只承载形制不复写判据与闸条款。

使用说明（固定）：⟪槽：…⟫＝每笔必填／必现跑槽位；未标槽段落＝预置固定行逐字照抄不改。模板本体纪律＝零反引号零 at；叙述面路径裸文＋全角斜杠；引文 ⟦⟧；命令一律缩进段。收口件一次成文；如需追加随正仅在尾续段 append，段间互不回改。

## 〇、开工读数（本席当轮现跑·禁抄旧数）
⟪槽：时点（date 现跑）⟫
⟪槽：HEAD 对钉（git rev-parse --short HEAD 与验收笔 sha 对拍＋与派工预期比对）⟫
⟪槽：链序（git log 现跑逐枚 sha→父 sha 相衔照登＋他票插笔归因注）⟫
⟪槽：锁态两态＋脏面照登（index.lock 两态处置＋tracked M 逐枚归因＋?? 当轮计数禁钉死）⟫
⟪槽：依据件 blob 双对钉（票面／快审判词／放行件／回执／验收判词逐枚＝链上 rev-parse＋盘面 hash-object＋行数成对）⟫
⟪槽：读数复用钉值＝当轮全文现读 QA 独立验收判词件时点 git rev-parse HEAD 全 sha 四十位（与判词件路径＋blob 成对登记）＝复用该判词登记读数的唯一前提⟫

    | 笔次 | sha＋尾标类别 | 落位件（行数·blob 双对钉） | 判定 |
    |---|---|---|---|

链账生成指引（预置固定·现跑口径＋H-1 接线后口径两段并列）：
    现跑口径＝链上枚数 git log 区间现跑；逐枚 sha／落位件／面单枚数＝git show --name-only 与 --numstat 现跑取证。
    ledger 接线后口径＝逐枚 hash＋性质读 .collab／ledger／ledger.jsonl 按 commit 尾标补记项对位生成，日终对账 reconcile-daily 承载；本表只誊账面读数不手改账。
