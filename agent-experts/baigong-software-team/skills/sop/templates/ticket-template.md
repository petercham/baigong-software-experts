# 票模板（SWB v2.9 · §3 票据四字段自包含＋票型九类·ADR 类据 2026-11-04 确认链增列）

> 本模板＝起草任何票据的骨架。票体四字段自包含：下游席位只读本票即可执行，不需外追他件。
> 修票权＝票类作者权（开发票→架构修｜缺陷票→QA 修｜部署票三字段→工程师部署域重写｜生产票目标字段→状态机依放行记录机械派生｜规则票→提案席位｜维护票→架构席修）。
> 工程师席不得改本票体四字段（§7 工程师席位纪律）。

## 票型九类清单（§3·与 config／ticket-types.json 同源）

1. 产品需求
2. 开发
3. 缺陷
4. 部署
5. 规则
6. 流程变更
7. 验收
8. 维护
9. ADR

＞ 票头登记票型必从上列九类取一；维护票＝轻量工作分支（载体走施工票通道、通道五类口径不变，准入四判据，未达判据转流程变更票重审）。
票型清单自校（预置·复算口径）：本清单枚数应与 config／ticket-types.json types 枚数相等；复算命令＝
  python -c "import json,sys; print(len(json.load(open('agent-experts/baigong-software-team/config/ticket-types.json', encoding='utf-8'))['types']))"
（缩进命令段内半斜杠＝shell 可用径体例先例＝钩子本体缩进段同制·叙述面仍全角）

## 票头（登记区）

- 票 ID：`YYYY-MM-DD-<域>-<编号>`
- 票型：〔九类取一〕
- 起草席位／修票权席位：〔按修票权映射〕

## 票体四字段（自包含）

### ① 目标

〔本票要达成什么；一句话可判的终态陈述。〕

### ② 规格

〔怎么做：逐条施工规格，含声明闭集＝本票唯一可写面（文件路径枚举）；禁动面（零触碰清单）。〕

### ③ 验收标准

〔全部机械可判：每条＝命令＋期望读数。例：〕
- `python -c "..."` 退出 0
- `grep -c 'PATTERN' <file>` ＝ N
- `ls <dir>/*.md | wc -l` ＝ N

### ④ 边界约束

〔票间关系（前置/后置）、同源与引用纪律、不消费未落盘件、回执落点与 commit 纪律。〕

## 租约段（票内·经架构签注由 B2 lease-issuer 实例化）

- deny_globs：〔越出即拒〕

T1（新规时间效力条款·十点裁第1条）：本规范全部条款只约束规范生效日以后创建的工单；
  存量工单一律不追溯、不回改、不登记补票。链上历史笔与既有票据零触碰。
T2（两轴正交条款·补裁点②）：票型（八类＝业务性质）与票种（四档＝效力性质）两轴并存，

  ＋§四 看板三层正交，引用入条款注释行）。
T3（票种条款形态条款·补裁点②带入成例二）：票种四档条款一律写成
  「主效力＋明示不含何种效力」形态：判定票＝主效力终局结论（同一对象现行判定票至多一张），
  不含改动授权、不含证词采信替代；证词票＝主效力证据陈述，明示不承载判定；
  施工票＝主效力改动授权（候裁定后生效），不承载终局判定；
  登记票＝主效力账目记载，不设定新权利义务。
T4（复审票取代／叠加二分条款·补裁点②带入成例一）：第二方复核须经人类裁定开复审票，
  复审票对原判定票的关系二取一写死：取代＝撤销口径＝原结论自始无效；
  叠加＝废止口径＝原结论有效至复审票生效点、向后失效。
  依据注释＝《党政机关公文处理工作条例》第33条二分成例（撤销自始无效／废止向后失效）。
T5（席位闭集条款·第3条）：票头「席位＝」字段取值闭集＝五席制
