# 回流件模板（SWB v2.9 · §3 回流件四型闭集）

> 工程师完工/中断回传必用本模板，态必从四型取一：**完成／部分完成／受阻／异常**（§3 回流四型闭集，其他措辞状态机拒绝登记）。
> 落盘路径：`.collab/returns/engineer/`（当票租约授权）；状态迁移经 `scripts/state-transition.py` 登记，不得口头回流。

## 回流头

- 票 ID：〔当票 ID〕
- 席位 ID：〔engineer 实例 Agent ID〕
- 实例 ID：〔本次新鲜实例标识（一票一新鲜实例）〕
- 回流态：〔完成｜部分完成｜受阻｜异常〕四取一
- 迁移登记：state-transition.py --return-type 取同一型值（完成→"完成"，四值逐字同；4→5 缺值状态机拒）
- 完工 HEAD：`git rev-parse --short HEAD` 实测读数
- commit：〔交付笔 hash〕

## 正文四节（自包含）

### ① 完成范围

〔已交付内容清单（文件级），与票面②规格逐条对位核销。〕

### ② 未完范围／阻塞点

〔部分完成＝列剩余项与原因；受阻＝直陈阻塞点与所需输入（哪张票/哪个席位/哪个人类触点）；异常＝异常五类取一（死信/挂起/熔断/超期/审计事件）＋触发码。完成态本节写"无"。〕

### ③ 验收自测读数

〔票面③验收标准逐条命令＋实测读数（申报载体，不自判合格——结论权在 QA/CI 面·制度③）。〕

### ④ 边界申报

〔越界零申报／写域外写入清单（应为空）；候裁处置单列；运行残留清理声明。〕

## 四型语义（技法细则）

- **完成**：票面②全部核销且③读数全绿。
- **部分完成**：核销一部分，剩余项明确可续接，无需外部解除阻塞即可继续。
- **受阻**：存在自身无法解除的阻塞（缺输入/缺授权/前置票未收口），等待指定输入方行动。
- **异常**：命中异常五类之一，同时应触发呈报（B4 呈报包，触发源六闭集取码）。
