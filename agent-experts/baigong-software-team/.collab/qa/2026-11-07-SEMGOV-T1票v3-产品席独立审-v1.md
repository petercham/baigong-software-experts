本席按"读 `verify.py` 每条 `cXX` 的判定语句、取主形态"独立归类（逐条依据见附录 A）：

| 结构（形态/正则/计数阈值） | c02 c03 c16 c18 c19 c21 c25 | **7** | 4 |
| 功能／元检查 | c20（8 样本实跑） c24（等长反义自检） | **2** | — |

**读二（变异体构成）**　票面 §0.5 原话：「197 条变异体 = 结构面 8（改名／嵌套目录／值互换／列互换／组件互换／子命令互换／删否定句／指针序位互换）+ 内容面 189（对方席 **31 条**原样复刻 + **49 靶点** ×3 算子）」。

### R6 §3.13 在真实仓必假红（回执路径 ABSENT ＋ 无行首裸键 ＋ `core.quotepath` 转义）

票面 §3.13 的命令逐字：

2. **真实回执无行首裸键**：`grep '^construction_commit_sha:'` 在真实回执上**零命中**（该件是在正文里叙述 commit sha，不是裸键行）。故即使把路径改对，`sed` 仍抓不到 → `RECEIPT_NO_SHA` exit 1。
3. **`core.quotepath` 转义**：在演练仓（仓外 `drill/`）跑正向，`git diff-tree --no-commit-id --name-only -r --root <sha>` 输出的是 `".scratch/tickets/2026-11-07-SEMGOV-T1-\346\212\200\350\203\275…"`（八进制转义形），与 `declared.txt` 里的中文名**不等**→ `diff` 失败、不出 `DECL_SET_EQUAL`。加 `-c core.quotepath=false` 后逐字相等。本仓 `core.quotepath` 默认为 true（实测）。

**已验成立的部分**（不抹）：负样本「回执键写成列表符 `- construction_commit_sha:`」→ `RECEIPT_NO_SHA` ✔；负样本「sha 改 64 个 0」→ `DIFF_TREE_FAILED` ✔（`set -o pipefail` 真生效）；`--root` 不可省的对照 ✔（不加输出 0 行 vs 加输出 7 行）。

**判**：这条是 v3 的"收束命令"，三条都必挂意味着**任何人在真实仓按票面跑 §3.13 都得不到 `DECL_SET_EQUAL`**。改法：路径改 `.scratch/tickets/2026-11-07-SEMGOV-T1-v3-receipt.md`（或把回执改落到 §④.1 声明的位置，二者取一，**并让 §④.1 与 §3.13 用同一个字符串**）；`sed` 前加 `-e 's/^[-*][[:space:]]*//'` 或把回执键改成裸键；`git diff-tree` 前加 `-c core.quotepath=false`（或在仓内设 `core.quotepath=false` 并写进票面前置条件）。
