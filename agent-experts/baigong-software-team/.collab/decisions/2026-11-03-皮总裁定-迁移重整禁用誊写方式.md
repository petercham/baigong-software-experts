# 皮总裁定 · 迁移重整禁用誊写方式（2026-11-03 20:4x）

> 裁定人＝皮总（决策者）；登记人＝主理人（誊录登记权·非判决作者）。

## 一、裁定原文（照录）

「注意，迁移重整一定是文件复制粘贴方式，千万不要用誊写方式」

## 二、口径登记（主理人侧操作化·不改裁定语义）

1. **辖域**：一切文件**迁移/重整/搬家**类施工＝仓重组 B 批（B1–B5 目录搬家）、落改随动中涉及整件移动者、退役移除等——文件内容必须**原样物理搬运**：`git mv`（保 rename 历史）或字节级复制＋删源；**禁止**以任何"誊写"方式重新生成文件内容（含"照录""逐字誊写批"式由 Agent 重新输出全文的形态）。
2. **理由（登记不代决策）**：誊写＝重生成，存在漏字/改字/编码漂移风险且机检对拍成本高；物理搬运天然字节等同、git 可直接验。
3. **既有先例定性**：本裁定**覆盖**此前「纯机械誊写批（FUXI-S0bP 先例体例）」形态在**迁移类**任务上的适用——MERGE-V11/V12/V13 剥壳落盘类"从源件生成新登记件"如属整件搬运＋局部剥壳，剥壳应改为**复制后机械删段**（字节级切片），不得重新输出全文。新建创作类件（设计稿、席位卡新节）不属辖域（本来就要写新内容）。
4. **随动义务**：在途/后续涉迁移票面须含判据「新位文件与原位文件 diff＝仅申报剥壳段／字节一致」；ES 案后续落改票、B 批迁移票、T09 落点整改票开工附注投放本条。
