## 二、誊录注记（主理人解释面·可否决）

1. 「高远见」按现行盘上实名核为「高见远」之笔误，映射对象明确＝架构席花名→**顾长远**（与架构席自拟候选「顾远鉴」同姓同意核，本裁定择「顾长远」）。
2. 英文面皮总未明示，主理人按既有构法（en＝姓氏拼音）默认随动，皮总可行使否决：
   - Qi→**Bao**（包好用）、Xu→**Jiang**（姜通透）、Gao→**Gu**（顾长远）、Kou→**Ke**（柯会码）、Yan→**Shen**（沈得严）
   - profession.en：Delivery Director→**Project Lead**；Product Manager 不变；Software Architect→**Architect Engineer**；Software Engineer→**Development Engineer**；QA Engineer→**QA Auditor**（即 QA 席自拟候选，获采）。
3. 头像文件名换代＝随同票执行（五席意见多数倾向改，`software-company-team-lead.png`/`software-product-manager.png` 等旧血统名 → 与席位 id 同族形态），图像本体不重制。
4. 席位 id（software-team-*）与席位卡文件名不动（寻址键·历史先例口径）。
5. 生效面＝注册卡＋包装卡＋五席位卡（frontmatter＋正文标题）＋技法卷正文句（如 standard-sop.md「产品经理（许清楚）」）＋README 随动；**历史链不改写**（历批回执/裁定/QA 件/commit 内旧名＝史实保留，自然断代）。
