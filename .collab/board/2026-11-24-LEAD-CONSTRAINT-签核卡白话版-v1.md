# LEAD-CONSTRAINT 签核卡（白话版 v1·手工装配面注明：decision-pack 无签核卡包型＝按决策包模板骨架手工装配）

## 案子一句话

把我（主理人）手里"自己能给自己开门"的权限收走：提交检查搬到 GitHub 独立机器上跑（我改不了）、降闸要您发一次性通行证、每天一双跟我不相干的只读眼睛查账直接报您。

## 需要您做的（按轻重排）

### 签1 · 降闸权移交（必签·核心）

- **改什么**：现在我提交时遇到闸报错，可以自己设个环境变量降闸继续（历史上降过 327 批，全是四枚旧欠账闸触发）。改后：每次降闸要先向您申请一次性通行证（写明事由和范围），我用您的签发凭证才能过；无凭证硬降＝当场红＋报警。
- **您的日常负担**：旧欠账（卫生票 T4）消化完后，预期接近零次；过渡期若集中修旧账，可能一次批几枚（按批次签发，不会天天找您）。
- **风险**：签发慢＝链暂停等您（已设超时转呈报不硬卡）。
- **怎么签**：回话写「签1 同意」或「签1 同意＋改法备注」。

### 签2 · 钥匙换小（您已亲践前两步·本笔为正式登记追认）

- **改什么**：本机存的 GitHub 大钥匙换成只能读写代码的小令牌（您 15:14 已手动换完；我已验证推拉正常）。剩下一步＝GitHub 上给主干加上"不许直接推、不许改历史"的保护锁——这把锁的开关权限从此只有您登录网页才有。
- **您的日常负担**：令牌 90 天左右续期一次（换令牌＝粘贴给我一分钟）。
- **风险**：小令牌权限如果勾错（勾了 Administration）＝锁形同虚设——T1 施工票里有探针臂专验这个勾（403 验证）。
- **怎么签**：回话写「签2 追认」＋可选要求我把令牌权限截图复核一遍。

### 签3 · CI 检查升格为强制面（登记生效·随呈带确认即可）

- **改什么**：外置物清单里 CI 原来记"托管面（坏了可降级）"；改成"链上强制面（坏了不许进主干）"。
- **您的动作**：无需单独签字，本卡回话里带一句「签3知悉」即可；有异议再单独提。

### 签4 · 哨兵席位注册（登记生效·随呈带确认即可）

- **改什么**：权限总表加一行"哨兵"席位：对仓只能读、写全部拒绝；由您的定时任务唤起，异常不经我、直接白话报您。
- **您的动作**：同上，「签4知悉」即可。

### 签5 · 边界确认（确认型）

- **确认内容**：这套方案只管"我动手"（提交、改文件、绕闸），不管"我说话"（呈报内容可信度仍由您把关＝呈报白话纪律那套）。三案零触碰语义面。
- **怎么签**：回话带「签5 确认」。
