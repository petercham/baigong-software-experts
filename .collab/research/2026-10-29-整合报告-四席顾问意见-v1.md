## 〇、四席总览（一句话立场）

| 席位 | 对合并的立场 | 一句话 |
|---|---|---|
| Hy4 | 不合产物，合引擎 | 「合引擎，不合产物；合接口，不合 schema」；真正红利在组合不在合并 |
| MiniMax | 合协议，不合 skill | 合并成一个协议＋两个 adapter＋两个 validator；治理层收益全在协议层 |
| GLM | 分清"合并"三义 | 融合＝错／编排＝对／组合＝务实；「合并的正确投资位置是测量层，不是提取层」 |
| Qwen | 有条件统一 | 统一入口＋动态路由/分层融合可行（注：其路由前提与我方平台显式注册制不符，趋势论不作依据） |

**收敛结论＝四席一致：反对 schema 级融合，支持共享内核＋本体分轨。** 分歧仅在共享层做多厚。

## 二、科学性评估：两个产品都不能直接照采信（Hy4/MiniMax/GLM 三席同构批判）

**总评＝工程流水线扎实，"验证"环节不科学。** 值得抄的是结构设计，必须重做的是验证。

### 真优点（值得采）
- 诱饵/负例测试（借自软件工程 negative testing）；产物强制写负例与边界。
- 淘汰留档＋coverage-audit（可审计性＝科学态度组成部分）；仓颉的自我限权（"合成基准≠实测""不得为通过改答案"）。
- 仓颉验证链可当模板：留出集 60/40 固定种子、三臂对照、机械断言（json_number 容差）先判再盲评。
- 溯源纪律（一手占比>50%、每模型≥2 场景证据）；保留矛盾不平滑；诚实边界/弃权要求与 Person Distillation 论文（边界探测协议、弃权四档）同向。

### 崩塌点（新设计必须避开）
1. **验证自指**：LLM 采集→提炼→验证→压测，裁判与被评同族。硬数据：AI 评审间一致 79.4%、与人类仅 56.9%；自我偏好 +70%；医学评测 judge-人类相关性 tau=−0.200；SkillLens（arXiv 2605.23899）LLM 自评 skill 质量准确率 46.4%。女娲引此文立铁律却全五维 LLM 打分、15 产物全员 A＝可疑分布。
2. **无 ablation**（最致命）：从未对比"蒸馏产物 vs 直接问 LLM 扮演该人"；25% negative transfer 数字（加 skill 比不加还差）证明对照不能省。
3. **语料泄漏**：已知问题回测测的是基座记忆而非蒸馏增量；需时间切分验证。
4. **N=1 无信度**：同料重蒸无 run-to-run 方差。
5. **数字无口径**：通过率 25–50% 无统计口径/评分者一致性（对比 K12-KGraph Fleiss' κ=0.84 才叫可核查）；评分权重无出处。
6. **公关形象蒸馏**：公开表达≠真实想法；幻觉会固化进产物并被每次调用放大。

## 三、合并问题的完整论证链（四席）

### 为什么 schema 级融合必坏（Hy4 四冲突＋GLM 四冲突＋MiniMax 三约束）
1. **抽取单元异类**：persona＝会思考的主体（常驻人格）vs procedure＝可执行程序（按需路由）；塞一个 schema 两边都变形。
2. **核心原则直接矛盾**（GLM·最深）：女娲"保留矛盾不平滑"vs 仓颉"边界明确、歧义消解"——同一套价值观当不了传记作者又当教材编辑。
3. **失败模式互斥**：人格侧防"编"（幻觉填充/公关蒸馏），技法侧防"调不出/误触发"；护栏完全反向。
4. **验证锚不可通约**（MiniMax·最致命）：技法锚＝原文（source_id+章节，可机械断言）vs 人格锚＝外部公开事实（弱、动态）；合并→门禁被拉到最弱档。
5. **追溯链断**：合并产物里一句话分不清"本人说的/书上写的/模型推的"——边界声明恰是最值钱部分。
6. **schema 字段互为噪声**＋token 膨胀注意力稀释；采集姿态相反（无文本即搜 vs 无文本即停）。
7. 现成反证：仓颉自身 322 技能 5.8 万字符目录负担的过度膨胀教训。

### 该合什么（收益全在共享层）
四席同构的共享内核清单：**语料纪律（来源优先级/一手占比/落盘纪律）＋阶段骨架（理解→并行提取→验证门→结构化落盘→测试件→边界声明）＋证据三级标注（他说过的/别人说他的/我推断的 ↔ source_id+位置）＋失败模式 if-then 表＋淘汰留档/coverage-audit＋快照/版本治理**。
- MiniMax 形态：L0 协议内核（只调度与门禁，不含领域判据）＋L1 adapters（person/method）＋L2 validators（source-anchor 硬门/public-anchor 软门+人工）。
- GLM：统一评估 harness（时间切分/naive 基线/污染探测/排他性测试）建在共享层——「投资位置在测量层」。
- 交叉嫁接增益：仓颉的留出集+机械断言补进人格验证器；女娲的泄漏检查+边缘诚实度补进技法验证器——合并的真实价值＝两套验证器互补短板，各自单独做不到。

### 必须保留的双轨（双输出标准）
- persona-IR（心智模型/决策启发式/表达 DNA/反模式/诚实边界）≠ technique-IR（R/I/A1/A2/E/B 能力卡）。
- 验证分轨：技法侧＝可确定性硬门（机械断言+对照+诱饵）；人格侧＝盲评 rubric+绝对线+decoy+泄漏检查+人工卡，**不得**用技法侧的确定性判据硬套（只会产生假阳性），也不得反向把人格软判拉进技法门禁。
- 失败模式与护栏分轨（防编 vs 防误触发）。
- GLM 补充·混合对象界：尼采型（人以其书为全载体）在 persona/technique 二分处断裂——理想处置＝persona 层＋technique 层双蒸双验的 bundle，这是划界清单必须覆盖的一条界。

### 合并已坏的自查信号（MiniMax）
IR 串味（人格卡出现步骤 1/2/3 或方法卡出现表达 DNA）／锚失去可回查位置／门禁统一到最弱（机械断言消失）。出现任一条＝退回分层。

## 四、达尔文 skill 的结论（四席提及）

darwin-skill＝对已生成 skill 做 8 维评分＋test-prompts 驱动的自动迭代进化。四席定位：生态第三环"蒸馏→验证→进化"（GLM/Hy4）；但属"事后打分、非回归"（MiniMax）。
**结论＝不并入产线本体，其可取思想已被验证层覆盖**：
- 自动改写产物升版与"人类评审闸＋版本受控"治理哲学冲突，且进化者＝被进化者＝自指循环（正撞第二节批判①）。
- 其真正可取件＝"测试题组驱动迭代"（test-prompts 当回归资产）——属验证层共享内核的应有物，不需要引 darwin 件本身。
- 产物＝调研时点快照、不自动演化；"快照陈旧"风险由复审/校准机制承接（Hy4 校准飞轮：每次产出标像/不像，"哪不像"逐条写回升版本——值得作复审语义收进共享治理层）。

## 五、新设计应划的界线（按四席收敛意见推导的候选界线集）

| # | 界线 | 一句话判据 |
|---|---|---|
| B1 | 基座/本体界 | 凡"任何一侧改动同时惠及双轨"的（语料纪律/阶段骨架/证据分级/留档/治理）入基座；凡含对象特有判据的（提取结构/提炼判据/卡体字段）不入基座 |
| B2 | schema 界 | persona-IR 与 technique-IR 永不相并；基座只调度与门禁，不含领域判据 |
| B3 | 验证闸界 | 技法＝确定性硬门（机械断言/对照/诱饵/留出集）；人格＝盲评+绝对线+decoy+泄漏检查+人工锚点；两侧判据不得互套 |
| B4 | 测量层投资界 | ablation/泄漏检查/run-to-run 方差/人工锚点一致率等评估基建建在共享层，一套 harness 服务两轨 |
| B5 | 对象分类界 | 输入分类＝人／书·技法／混合对象三类；混合对象走双轨 bundle 不单造第三 schema |
| B6 | 命名与产物界 | 双输出标准＝`-perspective` 与 `-technique` 两套产物规范各自成表（节闭集/声明措例/量纲）；产物为独立 skill 本体 |
| B7 | 追溯链界 | 产物内每要素三态标注（本人原文/第三方转述/模型推断）可回查；合并式产物禁止出现"分不清来源"的段落 |
| B8 | 生命周期界 | 常驻（persona）与即用即走（technique）两种装载语义分开，不做强行统一路由 |
| B9 | 演化界 | 版本升＝受控（tag/bump/复审＋人工闸）；自动改写进化不并入产线 |

## 六、给新会话的落地建议（按四席）

1. 先抽共享内核（证据分级＋失败模式＋产物契约＋审计留档）——四席一致认为纯收益零风险。
2. 再做两个 adapter（person/method），各自方法论从女娲/仓颉实证迁入。
3. 最后交叉加固验证器（这步动验证逻辑，须设计评审后动）。
4. 最便宜高值的第一件补强＝**人工锚点**：抽 10–20 个产物人工打分算 judge-人类一致率——把 46.4% 的 LLM judge 变成可信地基（MiniMax：比再蒸馏十套方法论都值）。
