## ① 目标

确立「通用工具归 shareds 料源＋装配时自包含嵌入使用方包后方可挂载」的落地路径并出可施工规格：终态可机械判＝每个被两包以上消费的通用工具，其**挂载面**（使用方包内可执行副本）经装配器从 shareds 料源生成，使用方包内代码不再以仓内跨包绝对路径引用他包工具；对拍口径＝装配幂等复跑零写入＋门禁 GATE PASS 态不变。

## ② 规格

### 背景条款（裁定在册·自包含照录）

皮总裁定口径：**通用工具归 shareds 料源，且必须装配时自包含嵌入使用方包后才可挂载。**即：工具真源单一住 shareds 料源面；各使用方包（百工专家包、各技能包）内挂载的工具副本＝装配产物，随包自包含，不依赖跨包运行时引用。

### 现状账（起草轮现读·盘上实物）

现盘通用工具三族分布：

1. 仓根 `tools/`：`check-source-of-truth.py`、`check-truename.py`、`count_agent_tokens.py`＋基线数据三件（baseline-seat-decl.json／baseline-sot-dup.json／check-truename-names.txt）。
2. `agent-skills/object-audit/scripts/`：`check-pointers.py`、`check-pointer-closure.py`、`check-ticket-reconcile.py`、`check-collab-lint.py`、`check-adr.py`、`check-entity.py`、`check-provenance.py`、`check-skill-meta.py`、`run-gates.sh`、`install-hooks.sh`。
3. `agent-skills/fuxi-skill/gates/`：`assert-tool.py`、`check-ticket-pins.py`、`harness-common.py`、`s0b-kappa.py`、`validator-catalog 族`（validator-public-anchor.py／validator-source-anchor.py）。

跨包引用实证（起草轮 git grep 现读）：他案票面与登记件普遍以仓根全路径引用 `agent-skills/object-audit/scripts/check-pointers.py`（如迁册票验收段），FUXI 线票面同时钉 `agent-skills/fuxi-skill/gates/check-ticket-pins.py` blob——两族工具的消费者横跨 FUXI／百工／SEMGV 多线；移交工单 v3 备注 4 亦载「check-ticket-pins 脚本住 devkits 工具域，其它项目复用需向该仓索取」＝复用无机制、靠人工索取的实证在册。

### 施工规格（放行后工程师席射程·定形不定文）

S1 料源归位：建 shareds 料源面（落点位候裁 H-1），把上述三族中**判定为通用**的工具迁入；判定口径三则写死——①被两包以上（含仓根治理面）消费＝通用；②仅一包消费且该包 gates 断言体系专属（如 s0b-kappa／validator 两件套）＝专属，留原包不迁；③基线数据文件随其消费者工具同迁不独立判定。

S2 自包含嵌入机制：装配链（bundle.lock 组件机制：`repo`/`path`/`target` 三字段已有跨仓搬移语义，见 `agent-experts/baigong-software-team/bundle.lock` conventions 段）增「shareds 工具组件」形态：使用方包 `components` 表内以 tag/commit 锁定 shareds 工具组件，装配时把工具文件整件嵌入包内 `tools/` 挂载位；挂载后的包内工具调用一律走包内相对路径。

S3 消费面随动：使用方包内席位卡／规程／门禁路由中的工具引用路径逐条改指挂载位；仓根治理面（无装配态）引用口径单列（候裁 H-2）。

S4 禁动面（零触碰清单）：工具代码逻辑本体零改动（纯搬迁＋引用随动，逻辑变更另案）；`agent-skills/fuxi-skill/gates/` 专属族不迁；三同源版本号零 bump（并入既有合并升号窗口）；史账（tickets／receipts／audits 既有面）零回改——旧路径字样按「新名生效点起按新名、旧文不追改」口径处置；链上历史笔不追改。

### 验收标准（全机械可判·命令＋期望读数）

- V1 `git grep -l "agent-skills/object-audit/scripts/check-pointers.py" -- "agent-experts/**"` 输出空（百工包内跨包引用清零）。
- V2 装配器对百工包 `--assemble` 复跑两次：第一次 exit 0 且 shareds 工具组件入包 `tools/` 挂载位（枚举计数＝声明数），第二次幂等零写入。
- V3 挂载态工具冒烟：包内挂载位副本独立跑 `--selftest`（有则跑之），exit 与料源版一致读数。
- V4 门禁族：`run-gates.sh` GATE PASS 态不变，BLOCK 族对开工基线零新增（逐条归因口径）。
- V5 纯净性：`git diff --name-only <开工 ANCHOR>..HEAD` 全集 ⊆ 票面声明闭集；他案 staged 面两读差集恰本笔面。

## ⑥ 候裁点（起草席不自拍）

- H-1 shareds 料源落位形态三取一：甲＝仓根新目录（如 shareds 桶）；乙＝现有 `tools/` 升格为唯一料源（object-audit／gates 通用族迁入）；丙＝独立组件仓以 tag 消费（最贴 bundle.lock conventions 的跨仓语义但成本最高）。席面建议＝乙（现盘 `tools/` 已是仓级工具域，迁移面最小），候裁。
