## 一、对抗审项逐号判色（红）

- **红一＝验收面零对抗（票面 V2 臂不支撑「可拦截」）**。夹具／模拟面与生产面 diff 计数 14／13 行＝模拟面为单分支（仅主形制）、无 stdin 面、无路径 trick、无 git 现势、身份硬编码；票面 V2「双向断言」两形＝无锚惰性／有锚 deny＝只测**管辖存续两态**，零测对抗绕行态（别名命令／输入件自写／身份冒用／路径注入全不在夹具射程）。＝「可拦截」结论的测试覆盖为零对抗样本。
- **红二＝生产链亦无真对抗**。读数＝commit-audit prehook 形态族＝amend／rebase／force-push／orphan 词面族拦（现跑 flip 后 rebase exit 2＋BLOCK 行在册），但**绕行族全过**＝现跑三形「git merge --squash BRANCH-A」「git revert --no-edit HEAD~1」「git commit -m fix -a」全 exit 0 NO_ASK；posthook 判定依赖自报 git_ref／身份字段，无外部 commit 对象核验＝自报即入账；「amend」可被 squash＋revert 复合形态语义等价绕穿。
- **红三＝判责可绕**。读数＝台账身份字段自报（现跑入账 author 可为任意值含 sim）；任务板 schema 现跑核验＝真包**无 board.py／lib 面在盘**（find 全零）＝无 author／git_ref／branch 约束字段＝谁干的＝写台账者说了算；deny 留痕与 commit 无绑定＝可指他人或幽灵席位。
- **红四＝管辖门可 toggle＋非幂等（锚门语义的对抗本体缺口）**。三步现跑：形一 pack 根无 .collab＝write-guard-sim 同径复跑 exit 0 惰性放行（＝票面宣称语义·绿四在册）；scan 一枚 HIT 呈报**副作用建台账**（FLIP_LEDGER_CREATED 读数）；形三同径同命令**翻转为 deny**（permissionDecision deny）＋commit-audit BLOCK。＝管辖判定输入件（锚／台账目录）在受管辖写面内＝**被管辖主体可自行建／删输入件自由开关闸门**；三枚脚本 project_root／governance_resident 探测口径三处互异（逐枚行号比对在册）＝同一路径可一枚判管辖一枚放行。票面 §二.7 四条件「机械可判」＝每枚脚本内部可判属实（绿四），**跨脚本一致性＋输入件不可篡改性零条款**＝中立放行语义自身即绕过门。
