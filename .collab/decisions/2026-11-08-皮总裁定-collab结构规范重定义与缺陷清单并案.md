# 皮总裁定登记·.collab 结构规范重定义与十一项清单并案

> 性质：主理人登记件（decisions 面·append-only）。开工 HEAD 实测读数＝`c848a78`（落笔前复点）。
> 本件＝对呈报件《collab目录结构审计如实报告与优化方案候拍-v1》（同笔 `c848a78` 落链）的正式裁定；上一呈报件中「产品写 prd、架构写 design/adr」系对现行规格的转述，其现行拆分方案本件起定性为**错误定义**。

## 一、皮总原话（逐字誊录）

> 产品写 prd、架构写 design/adr
> 1、是错误定义，因为 docs 内部的交接件总数就只有4件，所以 drafts 内部根本不需要再分子包，也就是我刚给的目录树 drafts 内部没有子包才是正确的。
> 2、adr 按之前的讨论记录，应属架构设计节点责任的，应该在 architect 下面。我补充一问：adr 有没有可能涉及产品需求变更？如果是应该单立 adr 目录，不在节点席位子包下。
> 3、drafts 内部的所有不同交接件草稿只能保留一件存活态的最新版本文档，凡过期版本均应入归档子包。.collab 内我没有列出来的子包可以有，继续保持即可。不同项目阶段用到的不同。我当前给的这6个只是在需求最终确认前阶段发现的问题和再次标准界定，因为发现了 drafts 的规范错误问题。
> 4、十一项清单联动并案处理。
> 按以上决策入账再出票

## 二、逐项入账

1. **drafts 分子包＝错误定义（定性）**：现 `seat-permissions.json` 的 `drafts/prd/`（产品）＋`drafts/design/`（架构）拆分方案废止。理由（皮总）＝docs 内交接件总数只有 4 件，drafts 内部不需要再分子包。裁定形态＝**交接件草稿直接落 `drafts/` 顶层，drafts 无子包**（归档子包除外，见第 3 项）。
2. **adr 归址**：皮总先记「adr 应属架构设计节点责任、在 architect 下面」，并附条件问「adr 有没有可能涉及产品需求变更？如果是应单立 adr 目录，不在节点席位子包下」。
   - 主理人取证回答＝**是**：①已拍 ADR 工序链（`b0b449d`）＝人类输入决策→主理人誊录→**产品席＋QA席＋架构席会签**→架构席终写——会签含产品席，即本团队制度设计已承认 ADR 可触及产品需求；②实证＝ADR-0001 实跑会签链中产品席出过「认可带保留 R-PM-1」（`b2150c5`）；③业界参照（Nygard《Documenting Architecture Decisions》2016）＝ADR 记录难以逆转的决策，常连带驱动需求调整（四件套出处已在 pm-adrpara 调研件在册）。
   - **按条件结构落裁定＝`.collab` 顶层单立 `adr/` 目录，不在 architect/ 下**。交付面 ADR 仍落 `docs/adr/`（既有工序链终写位不动）；`.collab/adr/`＝ADR 链在过程域的草稿与会签面。现 `drafts/adr/` 四件（草案/final/两份会签）随整改迁入。
3. **drafts 存活态纪律**：drafts/ 顶层每个交接件只保留**一件存活态最新本文档**；过期版本一律移**归档子包**（落位精确形态——`drafts/archive/` 或复用既有 `.collab/archive/`——由票面细节定）。未列出的子包（board/dispatch/evidence/inbox/process/receipts/refs/research/returns 及包内形态）**可以有、继续保持**，不同项目阶段用不同子包。**六目录定位＝需求最终确认前阶段的标准界定**（因发现 drafts 规范错误而做），非全生命周期闭集。
4. **十一项清单（`0259cd6`）联动并案**：候开票 B3（BLOCK 计数单一口径）、B4（scratch 取证清理规程）、B5（任务清单对账条款化）与本次结构整改**同批出票处理**，不单开。

## 三、裁定后目标六目录标准态（需求最终确认前阶段）

```
.collab/
  drafts/        交接件草稿：产品需求说明书、架构设计说明书等，顶层直接落件、无分子包；
                 每交接件仅一件存活态最新版；过期版 → 归档子包
  product/       缺口台账、报价单等非交接件（产品席法定写域）
  architect/     派单排期、函件套件、接口矩阵等非交接件（架构席写权域）——adr 不入此
  adr/           单立：ADR 草稿与会签过程面（跨席会签件，不属单席位节点子包）
  audits/        记账面不变（现实体名 qa/ → 名实对齐改 audits/）
  decisions/     记账面不变
  ledger/        记账面不变（现两处 untracked＝补 commit 入链）
  （未列子包：允许存续，按项目阶段取用）
```
