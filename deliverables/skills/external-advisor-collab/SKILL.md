# external-advisor-collab · 外部顾问讨论会治理

**定位**：决策者（皮总）× 主持人 × 多外部顾问席的多轮书面讨论会的程序与纪律——从三案历史讨论会（20261024／20261025a·b／20261026a）与项目记忆沉淀，不发明素材外规则。设计动机＝20261026a 案主持人七缺陷复盘（防其复发；素材来源与案史见 `references/90-changelog.md`）。

**真源边界**：本器只持外部讨论会**特有**的程序与纪律。仓内多席协作纪律（席位权限分级、交接件、A-17 轮次戳、三档表态制、讨论轮机制规则句、议题包五要素、引用治理 A-15）的真源在 multi-collab——需要处用指针（如「见 `multi-collab/references/30-formats.md` §六」），本器不复写。

## 核心红线摘要（详文见分卷，冲突以分卷与出处原话为准）

1. **主持人职权闭集**：只做程序＋现状答疑；绝不派调研/核验、不产观点、不替顾问补证（`10-roles.md`）。
2. **讨论对象永久红线**：只谈生产力工具，永不谈内容本体；产物只作工具失灵证据（`30-discipline.md`）。
3. **YAGNI 准入**：议题唯一来源＝验证中实际发现的问题；议题集外当场入候补池，出池＝对应工序实际暴露同类问题（`30-discipline.md`）。
4. **附件禁令**：附件提交＝形式非法不入件、对全体不可见、不计票基数；退回不记信誉（`30-discipline.md`）。
5. **决议规则**：全体顾问一致意见＝决议＝替皮总决策（讨论轮无皮总拍板）；第 1 轮不计、末次新提议轮后起算、满 3 轮无基本一致才上报；皮总保留议题否决权（`20-rounds.md`）。
6. **收口令三点**：一致决议＝权威决策（除非明确否决）；收口前核末次汇总确认状态；交付物确认关（交接件三方无否定无补充才呈收口）（`20-rounds.md`）。
