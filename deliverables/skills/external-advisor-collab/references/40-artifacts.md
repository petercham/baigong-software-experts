# 40 · 产物体例（六类件·最小骨架）

> 素材：三案历史讨论会话件（议题包／各轮汇总意见报告／答疑件＋答疑记录／决议稿／候补优化池——历史件不随包，体例要件全部由下列骨架自包含承载）。全部骨架自实物件提炼，未加素材外字段。落盘纪律：分发即落盘（主持人固定发言随记录件归档）；历史件不改，修订走新版＋版本声明（append-only）。

## §一 议题包（主持人 → 顾问，每轮一份）

**收敛类注**：收敛表态/签字/收口确认类议题包必含「§五 程序提示·合流与分歧清单」节（逐项待决议项 × 各席现行态度＋残余分歧）；该节要求真源见 `20-rounds.md` §二/§三，本处只标骨架位不复写。

```
# <轮次戳> · 第 N 轮议题包（<轮次性质>）
> 议题包编号｜轮次性质｜在录席位（票基数）｜发起｜随发材料清单
## §〇 轮次定位与前置声明   ← 本轮目标一句话；在录席位裁定；答疑发出状态；对象红线重申
## §一 随发材料清单          ← 表：#｜材料｜路径｜用途（均为盘上文件；不发附件）
## §二 任务（T-x-y 编号）    ← 每条：对象＋要求（逐条表态/择定＋理由）＋产出定义；实证锚列（YAGNI）
## §三 发言格式（硬闸）      ← 【来源】帽＋轮次戳；分节对任务编号；三档表态；标对象编号；inline
## §四 纪律提醒              ← 六类违例表＋退回流程＋附件禁令（每轮随发）
## §五 程序提示              ← 起算状态；决议效力；须另案呈拍项单列；收口前置；时限
```

## §二 汇总意见报告（主持人程序件·有新意见产出的轮次各一份）

> 适用域注：汇总件只属有新意见产出的轮次（发散/对位/交换）；**合流轮次（收敛表态/签字/收口确认）不发汇总件**——循环两式真源见 `20-rounds.md` §二，本处只标适用域不复写。

```
# 第 N 轮（<轮次性质>）汇总意见报告 vK
> 件级声明：讨论对象｜在录来源（合规回执清单）｜程序件声明（不表立场不代拟）｜轮次性质与新提议登记（起算是否重计）
## §〇 程序裁定登记          ← 在录地位/票基数裁定等（如有）
## §一~§n 逐任务对读          ← **逐条对位打勾表**：条目 × 各席表态矩阵＋对读结果（一致/新提议/待裁）
## §n+1 分歧登记              ← 编号 X-xx，各条附各方原始口径，主持人不判优劣
## §末 收敛状态               ← 一致项集合／待裁项／是否具备收口条件（判词前校验收敛对象有效性）
```

- 汇总三原则抬头：完整·准确·简练；顾问原话以回执件为准。
- 计数一律 occurrence 口径并声明；编号引用回原文对位（防漏列/错标——复盘缺陷六）。

## §三 答疑件 / 答疑记录（主持人义务件）

```
# 答疑件 — <对象>现状摘录（附路径＋行号）
> ①只答现状不表立场（不判优劣、不代拟整改、不给倾向）
> ②摘录纪律：盘上相对路径＋行号，逐字照录不改写；逐字条款逐字照录
> ③计数纪律：token 用具名口径脚本；文件计数 occurrence 口径
> ④讨论对象边界 ⑤答复状态：每问标「升 E 级／维持 H 级／不成立（附反证）」——判定权归发言席
## 问答登记
### Q-x｜提问席｜问题
**答**：摘录＋实测读数（引证：命令与输出）
```

- 提问通道：回执「候答清单」编号提问，或经决策者通道转问；随问随答不等回执。
- 留档：所有问答进《答疑记录》件，与讨论记录同效力，供后续轮次与收口件引用。
- 事实更正表（如有）：列「原结论 ↔ 现状事实」对读关系＋影响面；**只提供事实，不指示任何席如何修正结论**。

## §四 决议稿（收口成稿件）

```
# <议题>决议稿（外部顾问讨论会收口稿·vK）
> 决议性质（几方一致完全认可）｜成立依据（治理规则原话引用）｜成稿规则：正文＝签字对象逐字照录，
  不新增不改写立场｜汇总三原则｜确定性分级 L1（原话）/L2（主持人归纳）/L3（待拍）
## 一 决议地位与效力          ← 成立事实（签字轮＋行号锚）；起算规则两口径演算；效力边界
## 二 决议正文                ← 签字对象**逐字照录**（注明基准件与行号区间；机检实质行命中）
## 三 附列项闭环结果          ← 随决议生效部分，性质随条标注
## 四 记录性注记              ← 不改文本、不影响效力
## 五 呈拍事项                ← 须决策者亲拍者单列（不并入顾问决议）
## 六 轮次全程留档            ← 证据链表：轮次｜文件｜性质｜关键事件（commit）
## 七 落地接口                ← 决议对执行层的输入（指针）
## 八 签字记录                ← 表态矩阵：顾问｜各项表态（回执件行号锚）｜冻结声明｜收束语
```

- 编号迁移（如章节重排）＝纯编号对齐须登记依据与授权，签字基准件不可变。
- 交付物确认记录（收口确认轮）附于签字记录节。
- **呈拍事项·成稿自检判据**：列入「五 呈拍事项」节的事项须逐项标注＝`未收敛对立分歧`｜`决议明确留白且属决策者职权`——两类之外不得入本节（落笔时点的决议效力判据见 `20-rounds.md` §四，本处为决议稿骨架的成稿自检位，不复写）。

## §四之二 执行交接件（第六类件）

决议成稿后向执行团队交接的**干净决策件**（受众＝执行团队；只呈「决策＋理由说明」）。头部必带**件性声明行**：`性质＝交接件／决策件／施工输入`（此行为机检扫描面定位判据）。

```
# <件号> · <一句话主题>
> 性质＝交接件｜受众＝执行团队（闭集声明）
> 编号体系独立声明：本件编号独立于过程材料（如 R1–Rn 独立条款号＋内部节号引用）
## 一 决策正文        ← 自包含成文：收件人凭本件＋其盘上可达材料即可行动，无需回头问
## 二 理由说明        ← 每条决策附理由句；理由句不带出处
```

**三正面判据（可判）**：①**引用闭集可达**——收件人凭其输入闭集可核对本件一切引用；②**无第三方过程痕迹**——正文无他席立场来源过程信息；③**状态词只述现行效力**——不述「第几轮改成这样」式沿革（沿革归 `90-changelog.md`）。三判据的通用成文真源在 `multi-collab/references/20-handoff.md` §二（本处为讨论会侧引用，不复写）。

**讨论会特有禁列清单（正文内）**：席位名指涉他席立场来源、轮次号、提案编号（P-xx 式）、案卷行号（`0xx.txt:行号` 式）、〔席·轮〕注源、修正案史、除名/签字轮字样；禁「见第 N 轮汇总件 §x」式不可达指针（此句为**禁例**引用，本小节内此类字样只现于禁例语境且有标记）。
**帽保护句**：件级来源帽（【来源】<执行体>（<角色>））与既有硬性字段**不受禁列波及**——禁列射程＝正文内他席过程痕迹，不含件级署名。

**体例随受众判据**：件的受众在其输入闭集内可核对＝过程痕迹引用合法（复盘/审计/分析类治理件如此）；不可核对＝必须干净（交接件如此）。防交接禁则误展到过程材料类件。
