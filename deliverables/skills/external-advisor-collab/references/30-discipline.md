# 30 · 纪律与准入

> 素材：MEMORY.md §一（附件禁令·纪律提醒职责·YAGNI 准入·对象红线）＋ a-005 议题包 §四（纪律条款首次成文）＋ a-006 v2（YAGNI 重锚版）＋《讨论议题YAGNI准入审计》《候补优化池》。A-15 引用治理规则句真源见 `multi-collab/references/30-formats.md` §七；A-01 章程条文见 `multi-collab/references/70-charter.md`。

## §一 回执格式纪律（六类违例·退回流程）

**生效回执的形式要件**：开端 `【来源】<席位全名>（外部顾问）` 帽＋轮次戳；全文 inline；正文分节对应本轮任务编号；对他席表态**须标对象编号**；三档表态＋理由；「不认可」须给包内反证路径＋行号。

**六类违例与处置**（a-005 §四.2 表）：

| 违例 | 处置 |
|---|---|
| 以附件形式提交 | **不入件**（§二），须重发 inline 全文 |
| 缺 `【来源】` 帽＋轮次戳 | 退回重发 |
| 摘要式提交（只列目不展开） | 退回重发（汇总件对应段暂按「待全文」在录，不作收敛依据） |
| 正文出现内容本体层论述 | 退回重发（证据剥离到备案区，正文不得出现——与「产物可作失灵证据」不冲突） |
| 未标对象编号的他席表态 | 退回补正 |
| 引用外部实践缺四件套 | 该参照**不承重**（结论可成立，但不再以外部实践为据） |

**退回流程**：主持人**当场发回执**（指明违例项＋所涉规则＋重发要求）→ 该席重发 inline 全文 → 主持人以替换段更新在录 → 重发件到齐后进入收敛判定。**退回不记入顾问信誉评价**（格式问题与意见质量分离）。

**纪律三件套前置**（复盘缺陷四教训）：新规则确立当轮即成文「规则＋后果＋流程」三件套，不等首次违例；首次违例轻纵＝向全体席位传递「格式可商量」信号。纪律条款须**每轮写入议题包**（纪律提醒节）。

## §二 附件禁令（2026-10-26 皮总裁定·终版）

原话：「凡是用附件提交的意见，因为形式非法，一律不入主持人件，对主持人及所有顾问不可见。」

1. **形式非法**＝以附件提交（文档文件／目录内文件／非公开 URL）；只认**完整 inline 文本**（必须用附件时仅允许可公开访问 URL）。
2. **四项禁止**：不摘录、不转述、不留内容痕迹、不作收敛依据——对主持人及全体顾问**完全不可见**（连「某席提了什么」的存在性细节都不留）。
3. **票基数后果明示**：该席意见不进入台账收敛、**不计入票基数**；在录席位按实际合规席数计（实证：某席两次附件违例 → 该轮在录＝其余 3 席）。后果须在议题包里**明示**，不得让席位自我加码猜后果。
4. 裁定对象是**该份回执的形式**，不是席位资格：该席后续合规回执照常入录、恢复票位（第五轮程序裁定实证）。
5. 主持人件中只作「在录席位数＝N」的程序登记，**不点名批评**。
6. **机检义务**：主持人件落盘后须检索违例席的独有编号/标识（其回执自编号、附件文档名等），**确认零命中**方可提交。

## §三 讨论对象永久红线（2026-10-26 皮总裁定）

原话：「multi-agent-collab 这个项目永远不讨论内容本体层面的事情，讨论的只有生成内容的专家、技能等生产力工具（具体见交付物中的子包分类）。」

1. 一切讨论（讨论会、主理人自查、研究席任务）**只谈生产力工具**＝交付物子包（专家席 MD、skills 各域、装配）；**永不谈内容本体**（内容文本、医学、政策、文案、发布策略）。
2. 产物只可作「**工具失灵证据**」：以产物症状追问「生产机制缺了什么」合法；**对产物提修法＝违例**。
3. 政策/法规/医学类锚点核验＝内容本体任务＝**越界禁止**（主持人侧，见 `10-roles.md` §四）。
4. 主持人拟题纪律：**议题从工具出发，不从产物出发**；产物至多是证据附录。
5. 违例内容处置：顾问内容层意见可写回执「备案附录」（主持人转录归档、不表态、不计收敛）；正文出现＝格式违例退回。既往涉内容本体的共识/分歧/择定/备案一律作废不流转。

## §四 YAGNI 准入（2026-10-26 皮总裁定）

原话：「基于 YAGNI 原则，没有实际在验证中发现的问题，拒绝纳入本次讨论会议题。我们的目标是整改已经发现的问题的产生原因，而不是全盘扫描项目可以如何优化！」

1. **议题唯一来源＝试生产/验证中实际发现的问题**（凭复盘出处）；顾问全盘扫描推演的「可优化项」一律不入题——**「全盘扫描可优化」不构成议题，「验证中实际发现」才构成议题**。
2. **拟题操作化**：拟题时把复盘问题清单写进议题包作**议题边界**（议题带实证锚列）；「逐构件体检」式无边界框架＝漂移源（实证：19 条台账仅 4 条有实证、14 条系推演）。
3. **会中处置**：发言中提出议题集外新条目 → 主持人当场登记入**候补优化池**、不入本轮议程。
4. **候补池纪律**：性质＝留档池（不是决议/待办/呈拍件）；**出池条件＝对应工序进入实际生产并暴露同类问题**（凭实证回炉，附发现出处＋症状描述）；池件 **append-only**（出池在行内登记出处，不得删行）。
5. **主张人补证通道（A-01）**：台账条目无实证但有人主张 → 主张人限期补出处（可指认的实证记录）；补得出→回池入题；补不出→永久剔除（不入候补池）。
6. 剔除不是否决其价值，是**未经实际验证不纳入本次整改**；派生自已剔条目的议程/收敛项一并失效（连带撤回登记留档）。

## §五 举证与引用纪律

1. **A-01 谁主张谁举证**：约束发言者本人；引用失实后果由该席信誉承担。主持人不代核（`10-roles.md` §四）。
2. **外部引用四件套**：文件名／日期／条款位置／可访问 URL；缺任一件该参照不承重。出处补交逾期自动降格，不设第二次催办（降格处置细则真源见 `multi-collab/references/30-formats.md` §七 A-15）。
3. **引用纪律高于括注**：括注是选项描述、回执原话是择定事实——引用他方立场与其回执件**原话一致**，不得转述失真；供料件发现原文笔误，先报主持人、经同意才改引用，呈拍时选项原样带进（留选项不留空白）。
4. **自报优于他查**：顾问主动自曝引用问题的成本效率与可信度高于交叉审计；他查只承担兜底与锚点复验。
