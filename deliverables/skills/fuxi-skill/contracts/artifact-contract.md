# fuxi-skill · 产物契约（artifact-contract）

> 性质＝交付件本体（自包含成文·双纪律＝节闭集〔恰五节，多节/缺节/改名＝diff 非空即 fail〕＋字段名闭集〔本文件声明字段名与断言工具注册位双向 diff＝∅，未注册字段零容忍〕）。
> 记法：AC-<n>＝本文件节号；EG/FM-<n>＝同域契约文件节号（`evidence-grading.md`／`failure-modes.md`）；ST/FC/BW/GS-<n>＝断言目录编号（`gates/assertion-catalog.md`）；R<n>＝决策清单条款。

## AC-1 产物类型与元数据

两型产物＝perspective（person 轨）／technique（method 轨）；混合形态见 `编译形态` 取值 bundle（两层命名空间隔离判据＝FC-5，执行位在装配期，本契约只注册形态名）。

产物元数据字段名闭集（声明位·机读注册表）：

```json
{"字段注册": ["产物id", "所属轨", "编译形态", "快照时戳", "版本号", "复审到期日", "abstain_tier"]}
```

```json
{"值注册": {"编译形态": ["single", "pack", "bundle"], "所属轨": ["person", "method", "bundle"], "abstain_tier": ["有支持", "有限定", "无支持但貌似合理", "明确幻觉"]}}
```

- `编译形态` 取值闭集＝`single`／`pack`／`bundle`（B10/R23）。
- `快照时戳`＋`版本号` 承载快照/版本治理（A6）；`复审到期日` 承载复审节奏（A9，值规则＝AC-5 周期参数：快照时戳＋90 自然日）。
- 要素级结论字段 `abstain_tier`（拒答/弃权四档）：取值闭集＝{有支持, 有限定, 无支持但貌似合理, 明确幻觉}，与断言工具 BW-2 弃权四档注册值逐字全等；维度级结论必须落档其一。产物侧＝维度级结论的结论头字段；回归测试件侧＝ST-4 条目字段 `期望档位` 的取值闭集（同一词表，零分叉）。

## AC-2 状态字段

两字段两闭集（逐字与断言工具 FC-1 注册位全等；声明位＝机读值注册表，工具做双向 diff）：

```json
{"值注册": {"evidence_grade": ["人工验证", "机械断言", "LLM 判定"], "calibration_state": ["校准态", "待校准"]}}
```

- `evidence_grade`：证据获取方式轴（承 AC-3 三栏证据卡第一栏）；与 EG-2 `证据等级`（内容-来源关系轴）正交，不得互推互替。
- `calibration_state`：由 κ 计算结果自动驱动，不得人工声明；缺失或与 κ 报告不一致＝一律「待校准」并阻断放行（fail-closed，GS-4 校验器已就位）；非校准态者 judge 分数只作参考位（B12/R24）。
- 两字段名显式写入本契约（两轴正交）；字段名与取值两闭集与断言工具注册位逐字全等。

## AC-3 准入证据卡

每产物元数据面必含「准入证据卡」机读块，三栏＝三字段（卡口语义：三栏任一为「缺位/未测/未检」→ 记 `未验` 并不得进取门禁位）：

| 栏 | 字段名 | 取值闭集 | 互洽 |
|---|---|---|---|
| 证据等级栏 | `evidence_grade` | {人工验证, 机械断言, LLM 判定} | FC-1 逐字同集（值注册表见 AC-2） |
| 对照臂栏 | `control_arm` | {三臂, 无臂, 未测} | 三臂定义与三臂对照口径同一套（old/new/without）；「无臂」＝缺 without 臂读数→记未验不过闸（崩塌点触发位） |
| 泄漏检查栏 | `leakage_check` | {已检-不在语料内, 已检-在语料内, 未检} | 「已检-在语料内」触发 FM-P-04 泄漏处置；「未检」记未验 |

对照臂栏与泄漏检查栏取值闭集的声明位＝AC-2 同款机读值注册表（随 FC-1 声明块同区注册）：

```json
{"值注册": {"control_arm": ["三臂", "无臂", "未测"], "leakage_check": ["已检-不在语料内", "已检-在语料内", "未检"]}}
```

## AC-4 声明与措辞纪律

- 证据不足维度写「证据不足」不补全（与 EG-2 显式写法合法化衔接；不补全不是违规，隐式补全才是）。
- 改预期答案须独立理由和审计记录，不能为了通过而改答案。
- 发布数字必附统计口径＋样本量＋一致性系数三件套（BW-3 裸数字检出适用本契约全部报告面，含 coverage-audit 计数行）。

## AC-5 状态词表与看板

### 状态词表取值闭集

基线闭集（与 FC-4 注册位逐字全等，不扩）：`needs_review`／`active`／`归档区`／`待校准`／`未验`。

层级口径：`needs_review`／`active`／`归档区`＝产物级状态；`待校准`＝校准轴状态（与 `calibration_state` 同词同源，由 κ 自动驱动）；`未验`＝要素/读数级标记（三值报告缺一记「未验」等）。

「已核」语义不单设状态词：人工闸「已核实通过」的语义由看板「人工闸结论」栏自由文本＋对应产物状态保持/迁移到 `active` 承载（词表闭集锁定，扩词须走门禁面重交付程序）。

### 看板三栏契约

看板实例件格式（固定 markdown 结构，机检＝栏目名串扫描＋状态 token 扫描；实例落过程域案面＝交付面外，本契约只锁结构、词表与参数）：

- 文件头必含性质声明行「性质＝记录件·人工触发填写·非控制器」（缺行＝fail）。
- 三栏标题名闭集（FC-4 注册三栏）：`本轮改动`／`触发的坏信号`／`人工闸结论`。
  - `本轮改动`＝本表周期/事件窗口内对交付面 fuxi-skill 面的改动条目列表；无改动必须写「无」。
  - `触发的坏信号`＝四条坏信号（IR 串味／锚失去可回查位置／门禁统一到最弱／内部矛盾消失）＋FM 条目命中读数；无命中必须写「无」。
  - `人工闸结论`＝人裁处置记录，含状态词表取值 token；无议题写「无」。
- 实例文件名形态＝board-<日期>.md（kebab·日期段取填板当日）。

**「记录件非控制器」条款**：看板信号不得自动驱动任何产物改写、不产生任何状态迁移、不自动生效；一切状态迁移仅经人工闸结论＋独立提案＋版本审计生效。

### 阈值与周期参数（定稿值）

| 参数 | 定稿值 | 机检口径 |
|---|---|---|
| 填写触发 | 双触发制：①事件触发——任何一次对交付面 fuxi-skill 面的改动或任一状态词迁移，须在改动同轮填板；②周期兜底——每 14 自然日至少一板（无改动也填三栏「无」） | 相邻板文件名日期间隔 ≤14 天，超限＝fail（周期违规记未验并转人工闸议题） |
| 坏信号触发阈值 | 四条坏信号及 FM 条目命中计数 ≥1 即须填板（零容忍，无配额制） | 命中读数行扫描 |
| 悬置升级阈值 | 同一「未验」/「待校准」悬置项连续 3 个板次无状态迁移 → 强制列入人工闸议题 | 跨板 token 对账 |
| 复审到期日规则 | `复审到期日` ＝ `快照时戳` ＋ 90 自然日；越期未复审的产物 → 自动列入 needs_review 候选清单（列清单＝存证动作，不自动改写状态，须人工闸确认） | 日期差值扫描 |
