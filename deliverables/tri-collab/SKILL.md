# tri-collab · 协作纪律（权限分级版）

**v3.0（2026-10-22·皮总令）三处改**：①席位模型从"四席"改为**权限分级**——实践中读权席位早已 ≥3 类，席位表改为开放清单；②新增**文档交接机制**——需要交接的上下文转成自包含 md 交接件，这是权限隔离角色间唯一的协作介质；③体量瘦身——细则移入 references/（平铺一层），沿革移入 90-changelog。执行者唯一写盘（v2.4）**不变**，且仍独立成席。

**容器非真源**：纪律真源＝项目《开发纪律》M 层；条款带源锚，冲突时真源胜并修本器。本器不定义专业判据（票制＝`object-build/references/40-ticket.md`／身份＝`identity-governance`／文档治理＝`doc-governance`）。

## 总律（其余条款皆由此推出）

> **消息可以中转，判定不能中转；编制可以合并，利益不能合并。**
> 生产方不能自证；上行只增不改（拍板依据必须是原件），下行只减不加（执行者只拿干净指令）。
> 隔离的尺子只有一把：**这条信息对他完成当前那件事，是必需品还是噪音。**

## 权限分级模型（v3.0 核心）

| 权限级 | 席位 | 治理盘写权 | 交接区写权 | 读域 |
|---|---|---|---|---|
| **唯一写** | 执行者 | **有（唯一）** | 有 | 干净指令＋交接件（**不看讨论**） |
| 读权（开放清单） | 主理人（＝决策者席） | 无 | 有 | 全局（唯一） |
| | 审计者 | 无 | 有（判词/证据段） | 全局除执行内部 |
| | 顾问 | 无 | 有（本议题意见） | **仅议题包** |
| | 研究席 | 无 | 有（研究报告） | 受派议题 |
| | QA／其他子代理席 | 无 | 有（报告件） | 受派范围 |

**新增席位须声明三件**：读域（只给必需品）／产出形态（交什么交接件）／对谁（单一收件人）。**席位可增，两条永不变：治理盘写权只此一人；生产方不兼判定方。**

**两盘区分**：**治理盘**（docs／代码／测试／证据区）＝执行者唯一写（v2.4 不变，单写者才可对账）；**交接区**（项目指定目录，如 `.collab/inbox/`、`research/`）＝各席可写交接件，append-only、不改他人文档。交接区非治理盘——写它不属越权；落治理盘仍须走落盘分发。细则 `references/20-handoff.md`。

## 文档交接（权限隔离角色间唯一协作介质）

席位隔会话／后端／权限，**会话上下文传不过去**——凡尔虞我诈的口头共识，落不成文档就等于没交接。规则一句话：**需要交接的上下文写成自包含 md 交接件，不需要交接的不写。** 交接件五件（目的／收件人一个／自包含正文／来源／状态）＋自包含判据（接收方不必回头问＝自包含），细则 `references/20-handoff.md`。

## 消息路由（骨架·细则 `references/30-formats.md`）

主理人→审计者：任务意图·拍板·纠偏｜审计者→执行者：**干净指令**（七要素）｜执行者→审计者：报告·证据·阻塞｜审计者→主理人：判词·三态·呈拍。
**落盘分发**（主理人→执行者）只答「哪些件／原件在哪／回执给谁」——给工序判据＝双头指挥。
投递分件：一份文件一个收件人，审计件与讨论件物理分件。

## 六道硬约束（违反＝协作失败，不是风格问题）

1. **生产方不兼判定方**（唯一不可合并；审计的"全绿"也只是过程指标）。
2. **讨论不进执行通道**（未定被当已定、质疑被当否定）。
3. **上行只增不改，下行只减不加**。
4. **顾问只见议题**（有全局观就输出无授权链的"综合建议"）。
5. **L0 不下放**（判据／值域／验收标准＝人类独占；审计为放行放宽判据＝自发行医执照→停手上报）。分层表 `references/10-roles.md`。
6. **治理盘唯一写盘出口**（多席并行写＝写冲突＋格式漂＋无唯一责任主体）。

## 收口自检（机械核·声明收口前同一条列出）

①判据（原计划"验收："行）②逐条证据（文件:行／命令输出）③三态计数（绿＋未绿＋移出＝总数，**移出单列不计绿**）④未绿项（谁欠／欠多久／卡在哪）⑤移出项（移到哪·谁拍）。任一缺 → 只报「部分完成：X 已做／Y 未做」。
