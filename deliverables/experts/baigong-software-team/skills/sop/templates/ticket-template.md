# 票模板（SWB v2.9 · §3 票据四字段自包含＋票型八类）

> 本模板＝起草任何票据的骨架。票体四字段自包含：下游席位只读本票即可执行，不需外追他件。
> 修票权＝票类作者权（开发票→架构修｜缺陷票→QA 修｜部署票三字段→工程师部署域重写｜生产票目标字段→状态机依放行记录机械派生｜规则票→提案席位｜维护票→架构席修）。
> 工程师席不得改本票体四字段（§7 工程师席位纪律）。

## 票型八类清单（§3·与 config/ticket-types.json 同源）

1. 产品需求
2. 开发
3. 缺陷
4. 部署
5. 规则
6. 流程变更
7. 验收
8. 维护

> 票头登记票型必从上列八类取一；维护票＝轻量工作分支（载体走施工票通道、通道五类口径不变，准入四判据，未达判据转流程变更票重审）。

## 票头（登记区）

- 票 ID：`YYYY-MM-DD-<域>-<编号>`
- 票型：〔八类取一〕
- 起草席位／修票权席位：〔按修票权映射〕
- 开端读数：ANCHOR＝〔开工时实测 `git rev-parse --short HEAD` 附回执〕
- 前置票：〔票 ID 列表或"无"〕
- 候裁点：〔单列·起草席不自行拍〕

## 票体四字段（自包含）

### ① 目标

〔本票要达成什么；一句话可判的终态陈述。〕

### ② 规格

〔怎么做：逐条施工规格，含声明闭集＝本票唯一可写面（文件路径枚举）；禁动面（零触碰清单）。〕

### ③ 验收标准

〔全部机械可判：每条＝命令＋期望读数。例：〕
- `python -c "..."` 退出 0
- `grep -c 'PATTERN' <file>` ＝ N
- `ls <dir>/*.md | wc -l` ＝ N

### ④ 边界约束

〔票间关系（前置/后置）、同源与引用纪律、不消费未落盘件、回执落点与 commit 纪律。〕

## 租约段（票内·经架构签注由 B2 lease-issuer 实例化）

- path_globs：〔本票授权写入路径 glob 集（自表2-1 席位行子集）〕
- deny_globs：〔越出即拒〕
- 席位 ID／票 ID／哈希：由状态机签发，非人工填写

## 回执要求

完工回执落 `.collab/receipts/<票ID>-receipt.md`：开端 HEAD＋完整写入文件清单＋验收标准逐条实测读数＋候裁处置单列。
